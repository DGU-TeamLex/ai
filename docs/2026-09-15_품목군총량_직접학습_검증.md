# 품목군 총량 직접 학습 검증

## 실험의 근거

앞선 안정성 점검에서 2025년 8~9월 일부 품목을 묶어 계산한 WAPE는 약 25.51%였다. 동일한 품목의 개별 예측 오차가 없어졌다는 뜻은 아니다. 서로 반대 방향의 오차가 합쳐지면서 상쇄됐으며, 전체 품목별 WAPE 34.73%와 평가 대상도 달랐다.

다만 품목군 전체 사용량에 개별 품목보다 예측하기 쉬운 패턴이 있을 가능성은 검증할 가치가 있다. 이를 확인하기 위해 품목군 총량을 직접 학습하는 모델을 만든다. 기존 실험의 과거 비중 재배분과 달리 이번에는 총량 자체가 별도 모델의 예측값이다.

## 구현

동일 기관·부서·품목군·단위에서 두 품목 이상을 묶는다. 분류나 단위가 불명확하면 묶지 않는다. 각 품목의 과거 6개월 이상 기록과 필요한 과거 입력값이 있는 경우에만 해당 묶음을 사용한다. 모르는 값을 사용량 0으로 바꾸지 않는다.

입력은 묶음 안의 과거 사용량, 최근 평균, 입고량, 재고량, 월말 최근 기록, 품목 수와 달력 정보다. 정답은 해당 묶음에 있는 품목의 다음 달 사용량 합이다. 성분 자료나 진료·접종 자료는 이번 실험에 추가하지 않는다.

총량 모델은 LightGBM L1 손실, 최대 1,999회, 잎 31개, 최소 잎 표본 20개, 학습률 0.03, 2스레드로 고정한다. 개별 모델보다 그룹 학습 표본이 적으므로 같은 복잡도를 강제하지 않는다. 이는 총량 예측이라는 새 방법의 비교이며 변수만 하나 바꾼 비교는 아니다.

총량 예측값을 다음 두 방법으로 품목에 나눈다.

1. 기존 개별 예측의 비중으로 나눈다.
2. 과거 3개월 평균 사용량의 비중으로 나눈다.

비중 합이 0이면 해당 묶음 안에서 균등 배분한다. 품목 예측 합은 총량 예측과 같도록 검사한다. 이후 기존 예측에 총량 기반 예측을 25%, 50%, 100% 섞은 후보와 기존 예측을 비교한다. 부적격 품목은 기존 값을 유지하므로 전체 평가 행은 제외하지 않는다.

## 선택과 판정

- 2025년 4월까지의 정답으로 학습하고 5~6월 품목별 WAPE로 배분 방법과 혼합 비중을 고른다.
- 2025년 7월까지 다시 학습하고 8~9월에 선택한 방법만 확인한다. 이 기간에서 좋아지지 않으면 기존 모델을 유지한다.
- 선택을 기록한 다음 기존에 사용했던 10~12월 결과를 비교한다. 이미 여러 번 사용한 기간이므로 독립적인 성능 검증으로 표현하지 않는다.
- 전체 품목별 WAPE, BIAS, 묶음 적용 품목별 WAPE, 월별 결과를 제시한다. 총량 오차도 별도로 기록해 총량 예측과 품목별 배분 중 어디서 문제가 생겼는지 구분한다.

묶음 총량의 WAPE가 내려가도 전체 품목별 WAPE가 나빠지면 개선으로 채택하지 않는다. 총량의 정확도 향상이 올바른 품목별 발주량까지 이어지는지가 기준이다.

## 한계

매 예측 시점에 관측된 품목을 묶는다. 모든 달에 동일한 품목이 들어 있는 고정 묶음이나 기관의 전체 수요를 뜻하지 않는다. 원래 준비된 평가 자료의 관측 가능 여부에 따른 편향이 남아 있을 수 있다. 단위 이름이 같아도 포장 구성이나 임상적 대체 가능성을 보장하지 않는다. 이번 결과만으로 품목을 실제로 대체하거나 합산 발주하면 안 된다.

기준 모델도 각 과거 검증 기간을 조기 종료에 사용한 모델이다. 이번 비교는 기존 조건을 활용한 탐색 실험이며, 완전히 새 자료에서의 재검증은 아니다. 서비스 모델은 변경하지 않는다.

## 실행

`scripts/group_total_experiment.py`가 구현 파일이다. `outputs/group_total_v1`에 진행 상태, 기간별 결과, 선택 내역과 최종 비교를 저장한다. 테스트 5개로 총량 보존, 0 처리, 품목별 오차와 합산 오차의 차이, 정답의 입력 제외, 불명확한 단위 및 불완전한 과거 기록 제외를 확인했다.

```powershell
python scripts/group_total_experiment.py --source <기존모델및입력폴더> --output <새출력폴더>
python -m unittest discover -s tests -p test_group_total.py
```

## 실제 검증 결과

첫 검증(5~6월)의 전체 242,034행에서 기존 모델 WAPE는 36.3189%였다. 새 총량 모델을 25% 섞고 기존 예측 비중으로 나눈 후보가 새 방법 중 가장 나았지만, 36.3362%로 0.0173%p 악화됐다. 여섯 후보가 모두 기존 모델보다 나빴으므로 기존 모델을 선택했다. 새 총량 예측만 100% 사용하면 36.6315%, 과거 비중으로 100% 배분하면 36.8395%였다.

해당 기간 묶음 적용 표본 11,362행에서는 기존 품목별 WAPE가 30.4576%이고, 가장 나은 새 후보는 30.6266%였다. 이 표본의 총량만 평가하면 기존 개별 예측을 합한 값은 23.4275%, 새 총량 모델은 26.6621%였다. 따라서 첫 검증에서는 배분 단계 이전에 총량 예측부터 개선되지 않았다.

두 번째 검증(8~9월)의 5,270개 묶음에서도 기존 예측 합산 WAPE는 23.7824%, 새 총량 모델은 24.2554%였다. 총량 BIAS는 -8.7783%에서 -5.7502%로 줄었으나 총량 WAPE는 0.4730%p 악화됐다. 첫 검증에서 새 방법을 선택하지 않았으므로 두 번째 기간의 품목별 후보 순위를 다시 조정하지 않았다.

두 번째 모델은 학습 묶음 41,643개를 사용해 491회에서 최적 반복을 기록했다. 개별 입력 수백만 행을 임의로 표본 추출한 경량 실험은 아니다. 다만 분류·단위·과거 기록이 모두 확인되는 묶음만 총량 학습에 썼으며, 적용 품목 수가 적다는 제한이 있다.

이번 가설 검증에서는 새 총량 모델을 채택하지 않는다. 25%대의 합산 오차가 총량의 학습 가능성을 보장하지 않았고, 이번 설정에서는 이미 개별 모델을 합한 값이 더 정확했다. 이것이 모든 총량 학습 방법이 실패한다는 증거는 아니다.

실행은 정상 완료됐다. 재사용 평가 기간(10~12월)의 전체 359,335행에서는 기존 모델을 유지해 WAPE 34.7341%, BIAS -6.6320%로 재현됐다. 결과 JSON의 `improvement_pp: 0.0`은 새 모델이 기존 모델과 같다는 뜻이 아니라, 선택 절차가 기존 모델을 유지했다는 뜻이다. 새 총량 모델의 품목별 시험 결과를 보고 다시 후보를 고르지 않았다. 이 기간에도 총량 진단은 기존 합산 23.6865%, 새 총량 25.1567%로 새 모델이 나빴다. 이 진단은 후보 선택에 사용하지 않았다.

다음 가설은 총량을 새로 예측하는 것보다, 기존 개별 예측의 합으로 얻은 총량을 유지하면서 품목별 비중의 변화를 학습하는 방법이다. 기존 과거 평균 비중 재배분도 실패했으므로 단순 평균 배분을 반복해서는 안 된다. 동일 단위 안에서 과거 비중 변화·품목의 등장과 중단을 입력으로 쓰고, 과거 기간에서 먼저 성능을 확인해야 한다. 실제 대체 사용이나 진료량과의 관계가 확인된 것은 아니므로 이를 원인으로 단정하지 않는다.
