# GPU 수요예측 1차 비교

## 결과와 판단

RTX 5070 12GB에서 XGBoost GPU 학습을 실제 실행했다. 이번 설정에서는 기존 모델보다 WAPE가 나빠졌으므로 서비스 모델을 변경하지 않았다. BIAS는 음수가 작을수록 좋은 것이 아니라 0에 가까울수록 좋다.

- 기존 사용량 모델: WAPE 35.7032%, BIAS -7.5925%.
- 기존 Tweedie 모델: WAPE 37.5152%, BIAS -0.2482%.
- 기존 시간순 검증 혼합모델: WAPE 35.8008%, BIAS -5.8899%.
- 기존 두 모델의 고정 50:50 혼합: WAPE 36.1796%, BIAS -3.9204%.
- 최근 3개월 평균: WAPE 40.5323%, BIAS -6.0061%.
- GPU XGBoost 제곱오차: WAPE 42.7660%, BIAS +2.4759%.
- GPU XGBoost Tweedie: WAPE 41.8230%, BIAS +0.7240%.
- GPU 제곱오차 + 검증 구간 보정: WAPE 43.2727%, BIAS +4.7914%.
- GPU Tweedie + 검증 구간 보정: WAPE 42.8052%, BIAS +5.0239%.

GPU Tweedie는 기존 50:50 혼합 대비 WAPE가 약 5.64%p 악화됐다. 기존 Tweedie와 비교하면 WAPE와 절대 BIAS 모두 나쁘다. 따라서 GPU 모델이 더 정확하다는 주장은 성립하지 않는다.

## 실행 조건

학습 3,039,785행, 검증 246,103행, 평가 359,335행. 표본 추출 없이 해당 조건을 만족하는 전체 행을 사용했다. 전체 파일은 5,190,768행이며 날짜와 품질 조건으로 구간을 구분했다.

학습 원점은 승인된 2018~2019년 과거자료와 2024년 1월~2025년 6월이다. 과거자료 가중치는 기존 정책의 1.0을 읽어 사용했다. 이 특성표의 목표는 다음 달 사용량이므로 학습의 최근 목표 월은 2025년 7월이다. 검증 목표 월은 2025년 8~9월, 평가 목표 월은 2025년 10~12월이다. 예측 원점과 목표 월을 혼동하지 않도록 별도 필드로 처리했다.

사용한 입력은 지연 사용량, 이동평균·표준편차, 0 사용 비율, 이전 재고·입고량, 계절 등 25개 수치 변수다. 기관·품목 등 범주 변수와 외부위험 변수는 이번 실험에 넣지 않았다. 따라서 기존 모델과 입력 구성이 다르며 GPU만의 효과를 분리한 실험은 아니다.

XGBoost 3.4.1, device=cuda, tree_method=hist, 최대 400회, 깊이 5, 학습률 0.05, max_bin 64, CPU 스레드 2, seed 42. 검증 MAE가 40회 동안 개선되지 않으면 종료했다. 선택된 best_iteration은 제곱오차 202, Tweedie 139다. 동일 표본의 WAPE와 MAE는 분모가 고정되어 순위가 같다.

편향 보정 배율은 검증 실제값 합계 / 검증 예측값 합계를 0.8~1.2로 제한하여 계산했다. 평가 실제값으로 배율을 조절하지 않았다. 검증에서 과소예측을 보정했더니 평가에서는 과대예측이 더 커졌다. 총량 보정만으로 기간 변화에 대응할 수 없음을 보여준다.

학습·저장·비교·모델 사이 15초 휴식 두 차례를 포함한 전체 실행시간은 약 46.9초다. 별도의 합성자료 GPU 작동 확인은 약 0.23초였다. 이 시간은 다른 모델이나 데이터 전처리 전체의 소요시간이 아니다. 관측 시점 GPU 온도는 47도였지만 최대온도를 연속 기록하지 않았으므로 장시간 안정성 보장은 아니다.

## 한계와 다음 실험

이 평가 구간은 이전 실험에서 이미 확인한 구간이다. 새로운 외부 검증이라고 부를 수 없다. 한 시드, 두 손실함수, 제한된 설정의 결과이며 XGBoost 전체나 모든 GPU 모델이 열등하다는 뜻도 아니다. 조기 종료와 보정을 같은 검증 구간에서 수행했으므로 보정의 일반화도 별도로 확인해야 한다.

다음 후보는 범주형 품목·기관 정보를 포함한 CatBoost GPU와 별도 시계열 사전학습 모델이다. 우선 기존 모델과 입력 및 학습조건을 맞춘 비교가 필요하다. 설정 선택은 시간순 검증 구간에서만 수행하고, 이미 알려진 2025년 10~12월 결과는 사후 비교로 명시한다. 최종 개선 주장은 새로운 월 자료에서 확인해야 한다. 뉴스·원자재 공급위험은 사용수요 예측과 별도 목표로 평가해야 한다.

기관 담당자가 언급한 '피쳐'는 정확한 이름을 아직 확인하지 못했다. Feature는 입력 변수를 뜻하지만 특정 모델을 지칭했을 가능성을 배제할 수 없다.
