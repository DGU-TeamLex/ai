## 2. 결정을 내린 순서

### 1단계. 예측 대상 정의

재고량을 직접 맞히는 대신 다음 달 사용량을 먼저 예측하기로 했다. 현재고는 구매·반납·폐기
같은 운영행위의 결과라 수요만으로 설명할 수 없기 때문이다.

```text
사용량 예측 -> 재고정책 -> 목표재고/발주량
```

### 2단계. 가장 작은 신뢰 가능한 시계열 단위 선택

기관, 부서, 내부 물품코드를 로컬 시계열 키로 사용했다. 품목명 표준화가 덜 끝난 상태에서
기관 간 이름을 억지로 합치면 다른 규격과 단위가 섞일 수 있기 때문이다.

### 3단계. 시간 누수를 막은 모델 비교

과거로 학습하고 뒤의 6개월로 검증했다. 검증 WAPE가 가장 낮은 LightGBM L1을 선택했다.
테스트 구간에서 Tweedie가 더 좋아도 테스트를 선택에 다시 사용하지 않았다.

### 4단계. 외부 위험의 인과축 분리

질병 뉴스는 사용량 증가, 공급차질 뉴스와 원자재 가격은 조달조건 악화로 연결했다. 두
경로가 재고에 영향을 주는 방식이 다르기 때문에 하나의 점수로 먼저 합치지 않았다.

### 5단계. 승인 관계 우선

뉴스 키워드나 물품명 유사도만으로 재고를 바꾸지 않는다. 사람이 승인한 질병-품목,
품목-원자재 관계만 위험 전파에 사용한다.

### 6단계. 과잉 반응 상한 설정

가중치는 아직 정책 초기값이므로 위험버퍼가 보호기간 수요의 75%를 넘지 못하게 했다.
위험 수요가 이미 예측모델에 들어간 경우 정책층에서 다시 곱하지 않는 중복 방지도 넣었다.

### 7단계. 품질 게이트로 배포 분리

`PASS`만 운영 입력으로 허용하고 `REVIEW`, `BLOCK`은 검토 또는 격리한다. 현재 PASS가
0행이므로 최종 자동발주는 차단 상태다.

현재 모델 산출물이 해당 변형 추가 이전에 만들어졌기 때문이다. 승인된 0이 아닌 Module C
신호가 생긴 뒤 학습 산출물을 다시 만들어야 한다.

## 4. 10분 발표 구성

### 1:00~3:30 단순 재고량 모델

2. 월별 로컬 시계열과 시간순 검증을 보여준다.
3. LightGBM L1 검증 WAPE 40.19%와 3개월 평균 44.52%를 비교한다.
4. 예측 사용량이 기본재고와 발주량으로 변환되는 식을 보여준다.
5. `01_simple_inventory_output.csv`에서 혈당측정스트립 예시를 보여준다.

### 3:30~5:30 가중치 선정 모델

### 5:30~7:30 최종 결합 시스템

2. 승인 원자재 관계 0건, PASS 0행을 보여준다.

## 6. 예상 질문과 답변

### Q. WAPE 40%면 모델 성능이 낮은 것 아닌가?

전체 품목에 하나의 모델을 적용한 중간결과이고, 0 수요와 간헐수요가 많다. 3개월 평균보다
검증 성능은 개선됐지만 운영 완료 수준은 아니다. 품목군·수요패턴별 모델과 과소예측 보정이
다음 과제다.

### Q. 왜 테스트에서 더 좋은 Tweedie를 선택하지 않았나?

테스트는 최종 성능 확인용이다. 테스트를 보고 다시 선택하면 성능을 낙관적으로 추정하게
된다. 다음 시간 구간에서 challenger로 사전 등록해 비교해야 한다.

### Q. 가중치는 어떤 데이터로 학습했나?

아직 학습하지 않았다. 현재는 합이 1이고 출력이 제한되는 정책 seed다. 실제 품절·지연·사건
라벨과 승인 매핑이 확보되면 시간순 백테스트로 보정한다.

### Q. 외부 뉴스가 있는데 왜 위험 점수가 0인가?

뉴스 존재와 품목 영향 관계는 다르다. 승인된 품목-원자재 또는 질병-품목 관계가 없어
자동 조정을 차단했다.

### Q. 지금 바로 발주에 사용할 수 있나?

아니다. 최신 입력, 단위, 리드타임, 승인 매핑, 품질 PASS가 부족하다. 현재 결과는 구조 검증과
검토용이다.

### Q. 왜 수량이 소수인가?

모델 출력은 연속값이고 원천 단위가 아직 표준화되지 않았다. EA, BOX, TABLET 같은 단위가
승인된 뒤 품목별 반올림 정책을 적용한다.

## 7. 발표 직전 체크리스트

- 네 CSV가 스프레드시트에서 UTF-8로 열리는지 확인
- `operational_use_allowed=false` 컬럼을 숨기지 않기
- 시나리오를 실제 관측 위험으로 표현하지 않기
- WAPE와 정확도 `100-WAPE`를 같은 뜻으로 단정하지 않기
- 기본 리드타임 0일이 데이터 미연결 상태임을 설명하기
- 단위 미승인 상태에서 합계 수량을 발표하지 않기
- 현재 예측 대상월이 2026-01이고 stale임을 설명하기
