# 중간점검 1. 단순 재고량 분석 모델

작성일: 2026-07-22
발표일: 2026-07-23

## 1. 발표용 한 문장

과거 월별 사용량으로 다음 달 사용량을 예측하고, 검토주기와 조달 리드타임, 안전재고율을
적용해 위험 가중치가 없는 기본재고량과 발주 권고량을 계산한다.

## 2. 모델이 실제로 예측하는 값

머신러닝 모델의 직접 출력은 `다음 달 예상 사용량`이다. 재고량 자체를 바로 회귀하지
않는다. 예측 사용량을 재고정책 계산기에 넣어 다음 값을 순서대로 만든다.

```text
predicted_usage
-> protection_period_demand
-> safety_stock
-> base_stock
-> recommended_order
```

학습과 예측의 로컬 시계열 키는 다음과 같다.

```text
institution_code + department + item_code
```

기관의 같은 품목코드는 부서별 사용 패턴이 다를 수 있으므로 부서를 포함한다. 반대로
기관 간 품목 통합은 표준화 승인이 끝난 이후 별도 집계 단계에서 수행한다.

## 3. 입력 데이터와 분할

| 항목 | 현재 값 |
|---|---:|
| 원천 | `raw_stock/*.DAT` 10개 |
| 원천 논리 레코드 | 16,265,602 |
| 월별 집계 행 | 3,729,983 |
| 로컬 시계열 | 416,128 |
| 관측기간 | 2024-01 ~ 2025-12 |
| 학습 종료 | 2024-12 |
| 검증 구간 | 2025-01 ~ 2025-06 |
| 테스트 구간 | 2025-07 이후 |

시간 순서를 유지해 과거로 학습하고 미래로 검증한다. 무작위 분할은 미래 정보가 과거
학습 데이터에 섞일 수 있으므로 사용하지 않았다.

## 4. 비교한 방법과 선정 결과

| 모델 | 검증 WAPE | 테스트 WAPE | 테스트 Bias | 검증 선정 |
|---|---:|---:|---:|---|
| LightGBM L1 | 40.19% | 38.87% | -15.66% | 선택 |
| LightGBM Tweedie | 40.77% | 37.60% | -4.51% | 미선택 |
| 3개월 평균 | 44.52% | 40.02% | -6.04% | 미선택 |
| 전월값 | 48.07% | 44.75% | -3.66% | 미선택 |
| 전년 동월 | 54.92% | 52.67% | 2.99% | 미선택 |

`stock_model_a_usage_only` LightGBM L1을 선택한 이유는 검증 구간 WAPE가 가장 낮았기
때문이다. 3개월 평균 대비 검증 WAPE가 약 9.73% 상대 개선됐다.

테스트 구간에서는 Tweedie가 더 좋은 결과를 냈다. 테스트 결과를 보고 모델을 다시
선택하면 테스트 누수가 되므로 현재 선택은 유지했다. 다만 L1의 테스트 Bias가 -15.66%로
과소예측 방향이 강하므로, 다음 배치에서는 Tweedie를 운영 challenger로 재검증해야 한다.

## 5. 사용 특성

현재 선택 모델은 40개 입력 특성을 사용한다. 주요 범주는 다음과 같다.

- 최근 1, 2, 3, 6, 12개월 사용량
- 3, 6, 12개월 이동평균과 변동성
- 전년 동월 사용량
- 누적 평균
- 관측 개월 수
- 월 계절성
- 기관, 부서, 내부 물품코드
- 간헐수요를 나타내는 이력 특성

현재 선택 모델에는 뉴스, 원자재 가격, Module C 위험값이 들어가지 않는다. 따라서 이
단계의 결과는 외부 충격을 반영하지 않은 기준선이다.

## 6. 기본재고 계산식

```text
protection_period_days
  = review_period_days + lead_time_days

protection_period_demand
  = predicted_usage * protection_period_days / 30

safety_stock
  = protection_period_demand * 0.20

base_stock
  = protection_period_demand + safety_stock

inventory_position
  = current_stock + on_order_qty - backorder_qty

recommended_order
  = max(base_stock - inventory_position, 0)
```

현재 데이터에는 승인된 실제 리드타임이 없어 기본값은 다음과 같다.

| 정책값 | 현재 기본값 |
|---|---:|
| 검토주기 | 30일 |
| 조달 리드타임 | 0일 |
| 안전재고율 | 20% |
| 입고예정량 | 0 |
| 미납량 | 0 |

따라서 현재 단순식은 대부분 `base_stock = predicted_usage * 1.20`이 된다. 리드타임이
0이라는 것은 실제 조달이 즉시 된다는 의미가 아니라, 아직 데이터 계약이 없다는 뜻이다.

단위 표준화가 승인되지 않았기 때문에 출력은 소수점 값을 그대로 보존한다. `EA`처럼
이산 단위가 확정된 이후에만 올림 정책을 적용해야 한다.

## 8. 현재 해석 범위

현재 전체 예측 파일은 `outputs/stock_predictions.csv`이고 163,229행이다. 발표용 CSV는
이 파일에서 기관코드 형식, 이력 6개월 이상, 양수 예측, `UNCLASSIFIED` 제외 조건으로
100행을 추출했다.

현재 입력의 마지막 월은 2025-12이고 예측 대상은 2026-01이다. 발표 시점 기준
`data_age_months=7`이므로 운영 발주에 사용하면 안 된다. 이 출력은 모델 구조와 계산
방식을 설명하기 위한 중간점검 결과다.

### 재고 부족으로 관측되지 않은 수요

GitHub #24를 검증하면서 일별 마감재고 지속시간으로 수요 절단편향을 별도 계산했다.

| 분류 | 기관×품목 행 |
|---|---:|
| ACTIVE | 183,437 |
| DORMANT | 135,730 |
| CENSORED | 90,352 |

CENSORED 비율은 22.06%다. `mu_corrected`는 재고 보유기간과 품목 사전분포를 이용해
축소추정하고, 양수 관측 수요의 보정은 최대 10배로 제한했다. 검토가 필요한 58,516행은
자동 적재 대상에서 제외한다.

이 결과는 `outputs/demand_class_mu_corrected_handoff.csv`에 있지만 아직 위 LightGBM의
학습 라벨과 평가에는 결합되지 않았다. 따라서 발표용 단순 모델은 “잠재 수요”가 아니라
“실제로 출고된 사용량”을 예측한다고 설명해야 한다.

## 9. 발표에서 반드시 말할 한계

1. WAPE 40% 수준이므로 모든 품목에 동일하게 신뢰할 수 있는 완성 모델은 아니다.
2. 테스트에서 과소예측 편향이 확인됐다.
3. 실제 리드타임, 입고예정량, 미납량이 아직 연결되지 않았다.
4. 로컬 원천 단위가 표준화되지 않아 기관 간 합산과 자동 반올림을 금지한다.
5. 최신 원천 데이터가 없어 현재 결과는 stale 상태다.
6. 만성 결품으로 관측되지 않은 잠재 수요 보정은 계산됐지만 모델 학습과 SS/ROP에는 아직 통합되지 않았다.
