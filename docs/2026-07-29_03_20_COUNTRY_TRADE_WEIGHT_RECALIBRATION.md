# 20개국 무역 캐시 수집 및 세부 가중치 재보정

> 이 문서의 v1.3 성능은 최종 테스트를 별도로 두기 전 결과다. 최신
> 학습/검증/테스트 분리와 v1.4 결과는
> `2026-07-29_04_TEMPORAL_TRAIN_VALIDATION_TEST_WEIGHT_TUNING.md`를 기준으로 한다.

## 1. 결론

관세청 품목별 국가별 수출입 API로 승인 국가 20개국과 원자재-HSK 32개 조합을
모두 수집했다. 국가-HSK 체크포인트는 `640/640`, 총계 HSK는 `32/32`이며
중복 키는 0건이다.

20개국 자료와 다음 달 품절 대리목표를 이용해 무역위험 가중치 10개, 임계값과
가용성 게이트 10개, Module C 무역 overlay 1개를 재보정했다. 적용 정책은
`module-c-v1.3-trade20`이다.

시간순 홀드아웃에서 최종 정책은 실제 v1.2 전체 대비 가중 MAE를 6.58% 낮추고
Spearman 상관을 `0.0620`에서 `0.2373`으로 높였다. 다만 품절 대리목표를 사용한
검증이며 무역위험과 품절의 인과효과를 증명한 결과는 아니다.

## 2. 수집 결과

원천은 [공공데이터포털 관세청 품목별 국가별 수출입실적 서비스](https://www.data.go.kr/data/15100475/openapi.do)다.

| 항목 | 결과 |
|---|---:|
| 기간 | 2023-01~2026-06 |
| 승인 국가 | 20개 |
| 승인 HSK | 32개 |
| 국가-HSK 완료 | 640 / 640 |
| 총계 HSK 완료 | 32 / 32 |
| 총계 HS-월 | 1,340행 |
| 국가별 HS-국가-월 | 11,008행 |
| 국가별 캐시 키 중복 | 0건 |
| 총계 캐시 키 중복 | 0건 |
| 실제 응답행이 있는 국가 | 20개 |

국가코드:

```text
AE, BE, BH, CN, DE, ID, IN, JP, KW, MY,
NL, OM, QA, RU, SA, SG, TH, TW, US, VN
```

응답행이 없는 국가-HSK도 정상 조회 완료일 수 있다. 따라서 CSV 행 존재 여부가
아니라 `data/external/trade/kcs_trade_collection_state.json`의 완료 조합으로
수집 여부를 판정한다.

수집기는 다음 보호장치를 갖는다.

- 기존 캐시와 상태 파일을 읽고 누락된 국가-HSK만 요청한다.
- 각 국가-HSK 완료 시 상태와 캐시를 저장한다.
- CSV와 JSON을 임시 파일에 쓴 뒤 원자적으로 교체한다.
- HTTP 429, 5xx, URL 오류, 타임아웃을 지수 백오프로 재시도한다.
- 예상 요청량이 `TRADE_MAX_REQUESTS`를 넘으면 호출 전에 중단한다.
- 640개 국가-HSK와 32개 총계 HSK가 완료되지 않으면 보정 적용을 거부한다.

## 4. 보정 방법

보정 관측은 무역 특징과 재고 관측이 연결되는 HSK-월 713건이다.

| 구분 | 기간 또는 값 |
|---|---|
| 학습기간 | 2023-12~2025-05, 18개월 |
| 홀드아웃 | 2025-06~2025-11, 6개월 177건 |
| 대리목표 | 다음 달 `70% × 품절 발생률 + 30% × 평균 품절률` |
| 임계값 | 학습기간 양수 위험분포의 강건 분위수 |
| 분포 후보 | 가용률, 변수 간 중복도, 위험 표준편차 |
| 지도 후보 | 양수 Ridge와 분포 후보의 혼합 |
| 선택 기준 | 홀드아웃 가중 MAE, 동률이면 Spearman |
| 최종 안정화 | 선택 후보 80% + 기존 정책 20% |

임계값, 분포 진단, Ridge 학습과 점수 보정은 모두 학습기간만 사용했다. 홀드아웃
6개월은 후보 성능 비교 전까지 사용하지 않았다.

후보 중 `stockout_proxy_blend`가 선택됐다. 선택 후보 자체의 홀드아웃 MAE는
`0.02458`, Spearman은 `0.2457`이다. 운영 안정성을 위해 기존 정책 20%를 섞은
최종값은 MAE `0.02481`, Spearman `0.2373`이다.

## 9. 변경하지 않은 가중치

시장가격 3개 가중치, 뉴스·시장 공급위험 3개 가중치, 재고 조정 상한과 경보
임계값은 변경하지 않았다. 국가별 무역자료만으로 해당 신호들의 독립적인 예측기여를
식별할 수 없기 때문이다. 무역자료로 무관한 계수까지 보정하면 의미가 섞이고
홀드아웃 성능도 신뢰하기 어렵다.

## 11. 재실행

20개국 최초 전체 수집은 총계까지 포함하면 약 2,688회 요청이 필요하다. 승인된
API 호출 한도 안에서만 `TRADE_MAX_REQUESTS`를 올린다.

```bash
export TRADE_PROVIDER=kcs
export TRADE_REFRESH=true
export TRADE_MAX_REQUESTS=3000
python -m src.trade.trade_risk_scorer

python -m src.trade.trade_weight_calibration --apply
python -m src.trade.trade_risk_scorer --provider csv
python -m src.module_c.pipeline
python -m src.feature_engineering
python -m src.modeling.prediction
```

가중치 보정은 매일 실행하는 작업이 아니다. 국가 범위, HSK 매핑, 관측기간 또는
목표변수가 충분히 바뀌었을 때만 결과표를 검토하고 적용한다.
