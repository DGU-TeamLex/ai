# 사용 패턴별 별도 학습: 첫 단계

전체 TabM은 재사용 평가 WAPE 35.5118%로 기존 34.7341%보다 악화했다. 이미 학습한 모델들을 집단별로 골라 쓰는 방식도 첫 구간에서 선택한 규칙을 다음 구간에 적용하자 34.6920%에서 34.7733%로 악화했다. 같은 설정이나 선택 규칙을 반복하지 않는다.

이번에는 서로 다른 자료를 한 모델이 함께 학습하는 영향인지 확인하기 위해, 집단별 적격 자료 전체로 TabM을 처음부터 따로 학습한다. 집단은 예측 시점의 정보만으로 결정한다. 연속 이력이 6개월 미만이면 짧은 이력 집단으로 먼저 분류한다. 그 외 직전 사용량 0, 최근 3개월 변동계수 0.2 이하, 0.8 이상을 각각 별도 분류하고 나머지를 중간 변동 집단으로 분류한다. 이번 학습 대상은 짧은 이력 및 중간 변동 두 집단으로 고정한다. 다른 집단은 기존 모델을 그대로 사용한다. 이 분류는 임상적 상태를 의미하지 않는다.

근거는 과거 오차 감사에서 두 집단이 전체 절대오차의 약 73%를 차지했다는 점이다. 첫 학습 자료는 각각 1,545,935행과 539,576행이다. 데이터가 적은 집단만 선별해 낮은 WAPE를 보고하지 않고, 결과는 기존 전체 검증 242,034행에서 계산한다.

[MoLE 논문](https://arxiv.org/abs/2312.06786)은 시간 패턴에 특화된 여러 모델과 학습되는 결합 규칙을 제시한다. 본 실험은 이 아이디어를 참고한 고정 집단별 TabM 학습이며, 선형 전문가와 학습되는 결합 규칙을 사용하는 해당 논문의 재현이 아니다. 연구 성과를 우리 데이터의 개선 보장으로 인용하지 않는다.

입력 74개, 손실 및 정규화, 회차 선택, CPU 자원 제한은 PR120의 train_tabm.py와 동일하게 유지한다. 검증된 파일을 SHA256으로 고정하여 읽기 전용 의존성으로 사용한다. 해당 작업 폴더와 그 로컬 라이브러리 환경이 필요하며, 독립 배포용 패키지는 아니다. 스크립트가 달라지면 학습하지 않고 오류를 낸다.

2025년 4월 예측 대상까지 학습하고 5~6월로 1차 검사한다. 각 모델은 최대 30회·5회 무개선 조기 종료하며, 최저 검증 WAPE 회차를 저장한다. 두 집단을 모두 교체한 고정 조합이 전체 WAPE를 최소 0.3%p 개선할 때만 두 번째 시점 검증을 진행할 자격을 얻는다. 이 기준은 통계적 유의성 기준이 아니라 미미한 변화에 추가 자원을 쓰지 않기 위한 사전 중단 기준이다. 좋은 집단만 사후 선택하지 않는다. 1차 실패 시 이 설정을 중단한다.

현재 구현은 첫 단계 두 모델과 전체 표본 비교까지만 순차 실행한다. 8~9월 검증과 10~12월 재사용 평가는 읽지 않는다. 첫 단계 통과가 모델 채택을 의미하지 않으며, 후속 검증 없이 서비스에 반영하지 않는다. 5~6월 자료도 이전 연구에서 사용되었으므로 독립 확인으로 해석하지 않는다.

실행: model-family-search-20260913/.venv/Scripts/python.exe scripts/state_specialist.py. 실제 경로는 이 문서가 있는 작업 폴더 기준으로 ../model-family-search-20260913/.venv/Scripts/python.exe이다. 결과는 outputs/state_specialist_v1/screening.json, 진행은 events.jsonl 및 각 집단 하위 events.jsonl에 기록한다. 재부팅 후 자동 재시작하지 않고 기존 산출물을 보존한다. 메모리 1.5GiB 미만 또는 단계별 2시간 초과 시 본 작업의 하위 프로세스만 종료한다. 원본 자료·예측 행·모델 파일은 GitHub에 올리지 않는다.
