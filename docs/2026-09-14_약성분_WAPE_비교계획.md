# 약성분 추가에 따른 WAPE 비교

기존 74변수 직접 예측 모델과 동일한 설정에 정확히 연결된 약성분코드·용도구분·약종류구분·약품단위 4개를 추가한다. 기관 없이 약품코드만 일치하는 후보는 사용하지 않는다. 기존 입력과 정답은 연결 작업에서 모두 보존됐다.

## 고정 조건

- 기준 모델: residual-demand-20260914의 early/recent_direct_full 저장 모델. 검증 예측을 재계산해 기존 WAPE와 일치하지 않으면 중단한다.
- 학습: 기존 승인된 2018~2019년 자료와 2024년 이후 자료. 동일한 기간, L1 손실, 최대 1,999회, 2스레드, 검증 오차 기반 조기 종료 100회.
- 첫 검증: 2025년 4월까지 학습하고 5~6월 평가.
- 두 번째 검증: 2025년 7월까지 학습하고 8~9월 평가.
- 범주 목록과 결측 대체값은 학습 자료에서만 계산한다.
- 검증 4개월의 절대오차 합을 실제 사용량 합으로 나눈 WAPE로 선택을 먼저 기록한다.
- 이후 이미 사용한 10~12월 평가 기간에서 두 모델을 비교한다. 독립된 신규 평가가 아니므로 탐색 결과로 보고한다.

전체·월별·성분 연결 여부별 WAPE와 BIAS를 기록한다. 검증의 월 단위 재표집 2,000회로 WAPE 차이의 구간과 개선 방향의 비율을 계산하지만, 월이 4개뿐이라 불확실성을 충분히 추정하기 어렵다. 이 비율은 실제 개선이 참일 확률을 뜻하지 않는다.

## 제한과 실행

성분 원본의 적용 날짜가 없어 과거 시점에 실제 사용 가능했는지는 미검증이다. 성능이 좋아져도 이를 미래 실무 성능으로 확정하지 않는다. 같은 성분이 임상적으로 대체 가능함을 뜻하지 않는다. 진료·접종 변수를 추가한 실험도 아니다.

한 번에 한 모델씩 실행하고 사용 가능한 메모리가 1.5GiB보다 작아지면 해당 자식 실행을 중단한다. 이 제한이 전원·발열 문제를 해결하거나 강제 종료를 방지한다고 보장할 수는 없다. 서비스는 바꾸지 않는다.

```powershell
python scripts/ingredient_wape_experiment.py suite --input <연결입력.parquet> --baseline <기준모델폴더> --output <새출력폴더>
python -m unittest discover -s tests -p test_ingredient_wape.py
```

실제 출력 위치는 이 작업 폴더의 `outputs/ingredient_wape_v1`이다. `status.json`에 진행 상태, 기간별 JSON에 검증 결과, `results.json`에 최종 비교를 기록한다. `selection.json`은 과거 검증 결과로 결정한 선택이다. 원본·모델·대용량 결과는 Git에 올리지 않는다.

실행 시작 당시 테스트 5개 통과. 이 문서는 실험 계획이며 완료 또는 개선을 주장하지 않는다.
