- 작성일: 2026-08-18

- 작업 브랜치: `feat/external-risk-shock-residual-model`

## 0. 한 페이지 결론

이 연구는 단순히 다음 달 사용량을 맞히는 데서 끝나지 않는다. 물품재고 원장의 반품·정정값을
보존하면서 학습 가능한 수요를 분리하고, 수요를 예측한 뒤, 조달 리드타임과 예측 불확실성을
반영해 목표재고와 제안발주량으로 바꾸는 전체 흐름을 검증했다.

최종 판단은 다음과 같다.

1. **WAPE 기준 주모형은 수요전용 LightGBM L1이다.** 2025-08~12 전체 605,438행에서
   WAPE 35.714%로 최근 3개월 평균 40.022%보다 4.307%p 낮았다. 다만 BIAS -9.617%로
   과소예측 성향이 크다.
2. **재고정책 도전모형은 L1 50%와 Tweedie 50%의 고정 혼합이다.** 재사용 평가
   2025-10~12에서 WAPE 36.180%, BIAS -3.920%였다. 중간발표 관련 과거 원수치 37.184%,
   -3.467%와 수치상 가깝지만 모형·학습자료가 달라 선택 근거로 삼지 않았다. 동일 초기재고·30일
   리드타임 실험에서는 L1보다 미충족 수요가 2.52% 감소했다. 그러나 검증기간 BIAS가 -8.767%여서
   활성 정책에는 적용하지 않았다.
3. **중간발표 관련 저장소 원수치는 WAPE 37.184%, BIAS -3.467%다.** `37.16%`는 저장소의
   원수치와 일치하지 않는 전사값이고 `-3.5%`는 반올림값이다. 이 결과는 2018~2019 품목명
   정규화·엄격 연결과 패턴별 앙상블을 적용한 2025-10~12 평가값이다. 정책 JSON과 당시 문서에는
   남아 있지만 예측행·모형 번들이 함께 버전관리되지 않아 과거 기준값으로만 병기한다.[주 17]
4. **리드타임은 이번 연구 시뮬레이션에서 30일을 사용한다.** 나라장터 보건기관 계약
   10,109건의 p25·중앙값·p75가 30일이고 의료 관련 주요 세부품목도 30일이었다. 다만 계약상
   납기이지 실제 입고 소요일은 아니다.
5. **뉴스·원자재 신호는 실제 발주에 반영하지 않는다.** 전체용량 실험에서 원자재 신호는
   WAPE를 0.101%p 낮췄지만 BIAS를 0.227%p 악화시켰고, 외부신호 연결 표본도 전체의 약
   0.54%뿐이었다. 실제 권고와 분리된 병렬 시험값으로 유지한다.
6. **자동발주는 아직 승인할 수 없다.** 다음 신규 월, 실제 주문·입고·미충족·비용·유효기간
   자료가 없으므로 본 결과는 연구 후보와 조건부 발주식의 검증 결과다.

## 1. 먼저 알아야 할 용어

| 한글 용어 | 코드·영문 | 이 보고서에서의 뜻 |
|---|---|---|
| 실제 관측수요 | actual demand, `y` | 평가기간에 실제 발생한 양수 정상출고량 |
| 예측수요 | forecast, `ŷ` | 과거 시점 정보로 추정한 다음 달 사용량 |
| 단순 기준예측 | naive baseline | 지난달 값, 최근 3개월 평균처럼 학습 없이 만든 비교기준 |
| 조정 전 기준모형 | baseline LightGBM | 설정 탐색 전의 기본 LightGBM |
| 검증 조정모형 | tuned LightGBM | 시간순 검증자료로 설정을 조정한 LightGBM |
| L1 모형 | regression L1 | 절대오차의 중앙을 맞추는 손실함수를 쓴 LightGBM |
| Tweedie 모형 | Tweedie regression | 0이 많고 양수값이 치우친 자료를 위한 분포형 손실함수를 쓴 LightGBM |
| 재사용 평가 | reused evaluation | 이미 여러 실험에서 확인해 최종 미사용 시험으로 볼 수 없는 기간 |
| 병렬 시험값 | shadow value | 실제 권고에는 반영하지 않고 옆에서 효과만 비교하는 값 |
| 재고정책 검증 | inventory simulation | 과거 실제수요를 흘려보내 품절·평균재고를 비교하는 실험 |
| 목표재고 | order-up-to level, `S` | 다음 검토와 입고까지 버티도록 맞추려는 재고수준 |
| 재고포지션 | inventory position, `IP` | 현재고 + 발주잔량 - 미충족 주문량 |
| 제안발주량 | recommended order, `Q` | 목표재고에서 재고포지션을 뺀 뒤 0보다 작지 않게 한 값 |
| 자동 권고 차단 | quality gate | 데이터·매핑·검증 조건이 부족할 때 자동발주를 막는 규칙 |

`baseline`은 문맥에 따라 뜻이 달라 혼동되기 쉽다. 이 보고서에서는 산술 비교기는 `단순
기준예측`, LightGBM 비교대상은 `조정 전 기준모형`으로 구분한다. 코드의 `shadow`는 그림자
모형이나 논문명이 아니라 **실제 의사결정에 쓰지 않는 병렬 시험값**이라는 뜻이다.

## 2. 핵심 평가 공식

### 2.1 WAPE: 전체 오차의 상대 크기

```text
WAPE (Weighted Absolute Percentage Error, 가중절대백분율오차)
     = Σ |actual demand - forecast demand| / Σ |actual demand| × 100
     = Σ |y - ŷ| / Σ |y| × 100
```

WAPE는 낮을수록 좋다. 그러나 의료재고에 공통으로 적용되는 `30% 이하면 최적` 같은 보편적
합격선은 없다. 0수요 비율, 이력 길이, 품목 수와 평가기간이 다르면 난이도가 달라진다. 따라서
이 연구는 같은 행·같은 기간의 단순 기준예측과 비교하고 BIAS·품절·평균재고를 함께 본다.

### 2.2 BIAS: 과소·과다예측 방향

```text
BIAS% = Σ(forecast demand - actual demand) / Σ actual demand × 100
      = Σ(ŷ - y) / Σy × 100
```

0%에 가까울수록 전체 치우침이 작다. 음수면 실제보다 적게 예측해 품절 위험을 키울 수 있고,
양수면 과잉재고와 폐기 위험을 키울 수 있다. WAPE가 낮아도 BIAS가 크게 음수면 재고모형으로는
불리할 수 있다.

### 2.3 수요패턴: ADI와 CV²

```text
ADI (평균 수요발생 간격) = 전체 관측월 T / 양수 수요월 n+
CV² (변동계수 제곱)      = (양수 수요 표준편차 s+ / 양수 수요 평균 μ+)²
```

ADI가 크면 수요가 드물고 CV²가 크면 한 번 발생할 때의 양이 불안정하다. 안정형, 간헐형,
변동형, 불규칙 대량형을 설명하는 데 사용한다.[주 11]

### 2.4 50:50 편향보정 후보

```text
balanced forecast / 균형 예측
ŷ50 = 0.50 × ŷL1 + 0.50 × ŷTweedie
```

이 식은 논문에서 가져온 고정 정답이 아니다. L1의 낮은 WAPE와 Tweedie의 낮은 과소편향을
절반씩 결합한 설명 가능한 연구 후보다. 56% Tweedie가 현재 평가 BIAS에는 더 가깝지만 평가값을
보고 고른 비율이므로 채택하지 않는다.

### 2.5 목표재고와 제안발주량

```text
보호기간                         H  = 검토주기 R + 리드타임 L
보호기간 예상수요                 D_H = 월 예측수요 ŷmonth × H/30
비용 임계비율                     p* = 과소재고비 Cu / (Cu + 과다재고비 Co)
안전계수                         z* = Φ⁻¹(p*)
안전재고                         SS = z* × 월 불확실성 σmonth × √(H/30)
목표재고                         S  = D_H + SS
재고포지션                       IP = 현재고 + 발주잔량 - 미충족 주문량
제안발주량                       Q  = max(S - IP, 0)
```

이번 백테스트에서는 실제 비용비가 없어 서비스계수 `z=1.645`를 사용했다. 이는 경제적 최적값이
아니라 95% 서비스수준 가정이다. 실제 경제적 발주식은 보유·폐기·긴급구매·부족비가 들어온 뒤
다시 추정해야 한다.[주 12·주 13]

- 현재기간 월별 집계: 3,729,983행
- 익명 기관 3,530개, 부서 109개, 물품코드 17,155개

- 과거기간 월별 집계: 1,460,785행
- 2020~2023 공백: 보간하지 않고 2019와 2024 사이에서 시계열을 분리

구입단가는 현재 원천 16,265,602행 중 101,022행, 약 0.62%에서만 관측됐다. 따라서 전 품목의
금액 ABC나 실제 비용 최적화를 주장하지 않는다.[주 1]

### 3.2 음수만 기록된 달을 처리한 방법

정상출고량의 음수는 반품이나 과거 입력 정정일 수 있다. 원장값을 삭제하거나 양수로 바꾸지 않고
부호 보존값과 학습용 수요를 분리했다.

```text
부호 보존 원장출고 = Σ normal_outbound
양수 모델수요      = Σ max(normal_outbound, 0)
음수 건수          = count(normal_outbound < 0)
음수 절댓값        = Σ |min(normal_outbound, 0)|
```

| 사례 | 월 | 가명 기관 | 가명 품목 | 원장 합계 | 모델수요 | 설명 |
|---|---|---|---|---:|---:|---|
| 음수만 기록 | 2025-07 | H-cfb951b0 | H-188aa8e2 | -89 | 0 | 사용량 -89가 아니라 반품·정정 89로 보존 |
| 양수·음수 혼재 | 2024-05 | H-8263f413 | H-8a2081f4 | 18 | 19 | 양수 사용 19와 음수 조정 1이 함께 존재 |
| 양수·음수 상계 | 2024-06 | H-b4e0dfa4 | H-f7c34b9a | 0 | 4 | 원장 합은 0이어도 양수 출고 4는 학습 유지 |

현재기간에는 음수가 포함된 월 15개 중 음수만 기록된 달 1개, 양수·음수 혼재 달 14개가 있었다.
이 규칙은 문헌 공식이 아니라 원장 대사와 학습값을 혼동하지 않기 위한 데이터 계약이다.[주 2]

### 3.3 품목명·규격·단위를 정규화한 방법

여기서 정규화(normalization)는 수요량을 0~1로 바꾼 것이 아니라, 서로 다른 시기의 품목명을
같은 기준으로 비교할 수 있게 표기와 의미를 정리한 **품목 표준화**다. 실제 수요량·입고량·재고량은
원 단위를 유지하며 WAPE와 BIAS도 원 단위에서 계산한다. 처리 순서는 다음과 같다.[주 3]

```text
원시 물품명
→ Unicode NFKC·공백·기호 정리
→ 기관별 로컬 품목키 생성
→ 제조사·성분·제품명·제형·용량·함량·gauge·포장수량·단위 분리
→ 표기만 다른 이름을 대표품목으로 연결
→ 품목군·family·subtype·specification·unit 후보 생성
→ 공식 마스터·근거 사전 대조
→ 승인·충돌·미확정 상태와 연결 신뢰도 부여
```

| 키 | 뜻과 사용법 |
|---|---|
| `local_item_key` | 기관 내부 품목코드다. 물리 재고 시계열의 원래 경계를 보존한다. |
| `representative_item_id` | 띄어쓰기·기호·별칭만 다른 품목명을 같은 대표명으로 묶는다. |
| `standard_item_key` | 세부 규격까지 포함한 표준품목 125,557개다. 감사·추적에 쓰며 고카디널리티 과적합을 피하려고 LightGBM에 직접 넣지 않았다. |
| `standard_item_definition_key` | 품목군·family·subtype·규격·단위의 의미키다. 556,276개 매핑행에서 생성되어 모형의 범주정보로 사용됐다. |
| `stock_item_key` | 기관·부서·로컬코드를 유지한 실제 재고·위험 연결키다. |

전체 매핑은 585,279개 로컬 품목행이며 현재 409,519개와 과거 175,760개로 구성된다. 과거자료는
정규화된 전체 이름이 일치하는 `strict` 연결을 우선하고, 괄호와 끝 포장표기를 제거한 `core` 이름이
현재 표준품목 하나에만 대응할 때만 보조 연결했다. EA·ROLL·TABLET·ML처럼 단위가 다르거나 24G처럼
규격을 뜻하는 숫자는 합산하지 않았다. 이 절차로 과거 로컬 품목 146,757개(83.50%)를 학습에
사용했고, 이름 임시키만 있는 29,003개는 원본을 보존한 채 학습에서 격리했다.

품목 표준화와 외부위험의 0~1 점수 정규화는 서로 다른 절차다. 전자는 같은 품목을 판별하기 위한
문자열·의미 정리이고, 후자는 뉴스·원자재 지표의 서로 다른 척도를 결합하기 위한 점수 변환이다.

### 3.4 과거자료에서 연결하지 못한 사례

2018~2019 로컬 품목 175,760개 중 146,757개(83.50%)는 현재 대표품목과 엄격하게 연결됐다.
29,003개는 이름 기반 임시키만 있어 같은 품목이라고 확정할 수 없었다. 해당 143,736개 월별 행,
양수 모델수요 12,402,768.2116은 원본과 감사키를 보존하되 학습에서 제외했다.[주 3]

| 가명 품목 | 원문 품목명 | 연결방법 | 처리 |
|---|---|---|---|
| H-4c26d731 | `#6878 314 012 bur` | 과거 이름 임시연결, 신뢰도 0.50 | 학습 제외 |
| H-b218d7e4 | `#858 314 010 bur` | 과거 이름 임시연결, 신뢰도 0.50 | 학습 제외 |
| H-f9987eed | `#8878 314 012 bur` | 규격 차이 확인 불가 | 학습 제외 |

`제외`는 파일에서 행을 삭제했다는 뜻이 아니다. 잘못된 품목을 하나로 합치지 않도록 현재 모델
학습에서만 격리한 것이다. 공식 품목 대응표가 들어오면 다시 연결할 수 있다.

### 3.5 외부위험이 처음 반영되지 않았던 이유

고정 수요전용 스냅샷에는 뉴스 4개, 원자재 3개, Module C 8개, 총 15개 외부위험 열이 있었지만
학습·검증·평가 구간의 비영 관측이 모두 0개였다. 이는 `위험이 없었다`는 뜻이 아니라 외부위험
점수파일이 해당 특성생성 실행에 연결되지 않았다는 뜻이다.[주 4]

이후 동일한 대용량 원천 범위에서 외부점수 생성부터 모형 학습·평가까지 다시 실행했다.
외부신호 연결은 복구됐지만 연결 표본이 적고 최종 성능효과도 작아 실제 발주에는 반영하지 않았다.

수요전용 LightGBM은 51개 후보 특성을 사용했다.[주 9]

- 재고이력: 입고, 기말재고, 품절률, 폐기량의 과거값

- 원장품질: 부호 보존 출고, 양수 수요, 음수 거래 건수와 절댓값

평가월의 실제수요나 평가월 말 재고처럼 예측시점에 알 수 없는 값은 입력하지 않았다.

두 모형은 같은 `regression_l1` 손실을 사용하며 설정값만 다르다. 검증 조정모형은 4개의

### 6.2 중간발표 수치의 원출처와 정확한 표기

Git 이력과 PR·이슈를 다시 대조한 결과, 두 값의 원출처를 확인했다. 2026-07-29 커밋
`69678779`의 정책 JSON에는 2025-10~12 평가 359,335행에 대한 패턴별 앙상블 성능이
`WAPE 37.184025%`, `RMSE 200.653`, `BIAS -3.467129%`로 기록돼 있다.[주 17]

이 실행은 2018~2019와 2024 이후 자료를 그대로 붙인 결과가 아니다. 먼저 품목명을 NFKC·공백·
기호 기준으로 정규화하고, 전체 이름의 strict 일치 또는 하나의 표준품목으로만 연결되는 core
일치에 한해 과거자료를 학습에 포함했다. 이후 수요패턴별로 L1·Tweedie·Module C 가중치를
2025-08~09 검증구간에서 선택하고 2025-10~12에 평가했다. 즉 해당 수치는 **품목 표준화 과거학습과
패턴별 앙상블을 적용한 당시 모형의 유효한 결과**다.

따라서 `37.16%, -3.5%`의 정확한 해석은 다음과 같다.

- `BIAS -3.5%`: 원수치 -3.467129%를 소수 첫째 자리로 반올림한 값이다.
- `WAPE 37.16%`: 원수치 37.184025%와 일치하지 않는다. 같은 반올림 규칙이면 37.18%이므로
  발표자료 작성 과정의 전사·기억 오류로 보는 것이 타당하다.
- 당시 예측행 CSV와 모형 번들은 커밋되지 않아 동일 실행을 처음부터 끝까지 재생할 수는 없다.
  다만 정책 JSON·당시 보고서·PR #55·이슈 #39가 같은 수치를 가리켜 결과의 출처는 감사 가능하다.
- 이후 PR #93에서 L1 트리 수와 설정이 바뀌었으므로 현재 모형의 35.714%·-9.617%와 직접적인
  전후 우열로 비교하지 않는다.

최종 보고서에는 `중간발표 관련 과거 원수치: WAPE 37.184%, BIAS -3.467%`로 정정해 병기하고,
현행 모형 선택은 최신 동일조건 재현값으로 판단한다.

## 8. 30일 리드타임 근거와 효과

나라장터 종합쇼핑몰 품목정보 서비스에서 보건소·보건지소·보건진료소·보건의료원 계약을
집계했다. 2024년 1~6월 10,255건 중 유효 10,109건의 p25·중앙값·p75가 30일, p90이
60일이었다. 의료용살충제 3,289건, 백신 3,214건, 저출력심장충격기 250건, 방역용소독기
149건, 손소독기 98건은 p25·중앙값·p90이 모두 30일이었다.[주 10]

종전 15일에서 30일로 바꾸면 검토주기 30일 기준 보호기간은 45일에서 60일이 된다.

- 보호기간 예상수요 부분: `60/45=1.333`, 33.3% 증가
- 같은 불확실성의 안전재고 부분: `√(60/45)=1.155`, 15.5% 증가
- 최종 목표재고 증가율: 예측수요와 불확실성의 비중에 따라 다름

예를 들어 월 예측수요 3.5175, 15일 기준 안전재고 1.0552, 재고포지션 0을 그대로 비교하면
다음과 같다.

```text
15일: 보호수요 5.2763 + 안전재고 1.0552 = 목표재고 6.3315
30일: 보호수요 7.0350 + 안전재고 1.2185 = 목표재고 8.2535
차이: 1.9220, 약 30.4% 증가
```

이는 식의 민감도 예시다. 실제 발주량은 품목별 예측·불확실성·현재고·발주잔량에 따라 달라진다.
또한 30일은 계약 납기이며 실제 입고 소요일이 아니므로 운영 확정값으로 표현하지 않는다.

## 10. 외부위험 병렬 실험

### 10.1 뉴스·원자재 공식

```text
기사점수 = exp(Σ αk × log(wk)),  Σαk = 1
월 위험점수 = 1 - exp(-Σ 기사점수 / 같은 위험군 p90 척도)

일별 원자재 30일 변동성 = 30일 수익률 표준편차 × √30
주별 원자재 30일 변동성 = 주별 수익률 표준편차 × √(30/7)

원인군별 위험 rc = 같은 원인의 경로위험 중 최댓값
Noisy-OR 복합위험 = 1 - ∏c(1 - rc)
```

기사점수와 복합위험은 사건 발생확률이 아니다. 같은 충격을 뉴스·가격·무역에서 중복 측정할 수
있어 같은 원인군 안에서는 최댓값만 남기고 서로 다른 원인군 사이에서 결합했다.[주 14]

### 10.2 전체용량 최종 결과

전체 20개 과업, 모델당 트리 1,999개, 월 블록 부트스트랩 500회를 완료했다.[주 5]

| 후보 | WAPE | 수요전용 대비 변화 | 95% 구간 | BIAS | 판정 |
|---|---:|---:|---|---:|---|
| 수요전용 L1 | 36.966% | 기준 | - | -6.361% | 기준 |
| 뉴스 | 36.957% | -0.009%p | -0.072~+0.042 | -6.652% | 유의하지 않음 |

외부신호 연결 표본은 7,544행, 강한 충격 표본은 3,166행으로 전체 1,403,923행의 약
0.54%, 0.23%다. 뉴스+원자재 결합은 강한 충격 구간 WAPE를 42.48%에서 41.81%로
0.67%p 낮췄지만 BIAS는 -4.01%에서 -5.00%로 악화됐다. 비충격 구간에서도 비슷한 개선이
나타나 충격 특화 효과라고 보기 어렵다.

잔차 보정은 5,995행을 바꿨지만 전체 평균 절대 예측변화가 약 `7.6×10⁻⁸`이어서 실질적으로
작동하지 않았다. 원자재 신호는 별도 경보·설명정보로 남기고 수요예측과 실제 발주에는 넣지 않는다.

## 11. 자동 권고 차단 규칙

자동 권고 차단은 성능지표가 아니라 근거 부족 행이 발주권고로 넘어가는 것을 막는 규칙이다.

```text
장기 무수요·미운영             → 제안발주량 0
자료누락·오래된 관측           → 자동값 없음, 사람 검토
품목·원자재 연결 충돌          → 외부위험 반영 차단
외부위험 독립검증 미통과       → 기본 제안발주량 유지
승인 동등품 재고 존재          → 긴급부족 표시 억제
```

원본 데이터가 운영 시점보다 8개월 오래된 것은 본 실험에서 의도된 조건이다. 연구 재현과 과거
평가에는 사용할 수 있지만 현재 실제 발주량으로 해석하지 않는다.

## 12. 최종 선택과 주장 수준

목적이다. 따라서 최종 발표의 대표값은 50:50의 `WAPE 36.180%, BIAS -3.920%`로 제시하되,
반드시 `재사용 평가·도전모형·미적용`이라는 설명을 함께 붙인다.

## 13. 확인된 한계와 개선 우선순위

### 13.1 확인된 한계

1. 2025년 하반기를 반복 확인해 깨끗한 최종 미사용 시험기간이 없다.
2. 중간발표 원수치와 평가계약은 복원했지만 당시 예측행·모형 번들이 없어 완전 재실행은 불가능하다.
3. 50:50의 검증 BIAS와 평가 BIAS가 달라 기간 안정성이 충분하지 않다.
4. 외부신호 연결 표본이 전체의 약 0.54%이며 질병 수요위험은 여전히 실증이 부족하다.
5. 계약 납기 30일과 실제 주문일부터 입고일까지의 소요일을 구분해야 한다.
6. 발주잔량·부분입고·미충족 자료가 없어 실제 재고포지션을 완전히 재현하지 못한다.
7. 보유·폐기·긴급구매·부족비가 없어 경제적 최적 발주량을 확정할 수 없다.
8. 2020~2023 자료 공백과 중앙 관측월 6개월 때문에 개별 품목 분산이 불안정하다.

### 13.2 다음 순서

1. 다음 신규 월에서는 혼합비를 바꾸지 않고 L1·현재 혼합·고정 50:50을 한 번 비교한다.

3. 요청량·충족량·미충족량으로 손실판매 가정을 검증한다.
4. 단가·보유비·폐기비·긴급구매비·부족비로 `p*`와 `z*`를 다시 추정한다.

## 16. 최종 결론

수요전용 L1은 WAPE가 가장 낮지만 과소예측 편향이 크다. Tweedie는 편향과 RMSE가 우수하지만
WAPE가 높다. 두 모형을 50:50으로 고정 결합하면 재사용 평가에서 WAPE 36.180%, BIAS
-3.920%가 되고, 동일조건 30일 리드타임 재고실험에서 L1보다 미충족 수요가 2.52% 감소한다.
발주량은 1.94% 증가하므로 개선은 공짜가 아니며, 충족률 개선폭도 0.051%p로 작다.

따라서 최종 연구결론은 **L1을 WAPE 주모형으로 유지하고 50:50을 재고정책 도전모형으로
제안하되 실제 정책에는 적용하지 않는다**는 것이다. 다음 신규 월이 들어오면 비율을 다시 맞추지
않고 한 번 평가한다. 외부위험은 원자재에서 작은 WAPE 개선이 있었지만 연결 희소성과 편향 악화
때문에 병렬 시험으로 유지한다. 30일 리드타임은 계약자료에 근거한 연구값이며 실제 주문·입고
자료가 들어오면 교체한다.

이 결론은 중간발표 수치를 억지로 유지하기 위한 것이 아니다. 현재 저장소에서 재현할 수 있는
데이터·산식·평가계약으로 수요예측과 재고성과를 함께 설명하기 위한 최종 판단이다.
