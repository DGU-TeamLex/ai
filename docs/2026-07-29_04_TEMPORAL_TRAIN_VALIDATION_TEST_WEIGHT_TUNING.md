# 최신 검증·테스트 분리 기반 가중치 보정

> 후속 변경: 표준화된 2018·2019년 학습자료와 새 LightGBM 모델을 적용한 최신
> 성능 및 가중치는 `2026-07-29_06_STANDARDIZED_HISTORY_LIGHTGBM_UPDATE.md`와
> `2026-07-29_07_MODIFIED_RESULTS_PERFORMANCE_AND_OPERATION.md`를 기준으로 한다.

## 1. 결론

기존 재고 데이터를 시간순으로 분리해 모델 학습, 가중치 선택, 최종 테스트가 서로
섞이지 않도록 수정했다.

사용량 예측은 2025-06까지의 데이터로 모델을 학습하고, 2025-08~09에서 세 모델의
혼합 가중치를 선택했다. 선택에 사용하지 않은 최신 2025-10~12 테스트에서 현행
L1 단일 모델과 비교했다.

검증에서 선택된 방식은 수요유형별 가중치 라우터다. 최신 테스트 WAPE는
`39.05% → 37.58%`로 1.47%p, 상대 3.78% 개선됐다. RMSE는 32.28% 낮아지고
과소예측 Bias는 `-14.98% → -6.40%`로 완화됐다.

무역 가중치도 기존 학습/검증 2분할에서 학습/검증/테스트 3분할로 바꿨다. v1.3
대비 최신 3개월 테스트에서 품절 대리목표 MAE가 0.91% 개선돼
`module-c-v1.4-trade20-temporal`로 적용했다.

## 2. 시간 분할

### 사용량 예측

| 단계 | 기간 | 행 | 사용 목적 |
|---|---|---:|---|
| 기본 모델 시간순 교차검증 | 2025-01~2025-06 | - | L1·Tweedie·Module C 모델 비교 |
| 최종 모델 재학습 | 2025-06 이전 전체 | 2,087,782 | 세 모델 파라미터 재학습 |
| 혼합 가중치 검증 | 2025-08~2025-09 | 246,102 | 5% 간격 가중치 선택 |
| 최종 테스트 | 2025-10~2025-12 | 359,335 | 선택된 정책을 한 번만 평가 |

최종 모델은 검증 종료인 2025-06까지 재학습한다. 혼합 가중치 검증과 테스트의
실제 사용량은 모델 학습에 포함하지 않는다.

### 무역 가중치

| 단계 | 기간 | HSK-월 | 사용 목적 |
|---|---|---:|---|
| 학습 | 2023-12~2025-05 | 536 | 임계값·분포·Ridge 후보 생성 |
| 검증 | 2025-06~2025-08 | 88 | 후보 가중치 선택 |
| 테스트 | 2025-09~2025-11 | 89 | 현행 v1.3과 최종 비교 |

테스트 구간은 가중치 선택과 Module C overlay 산정에 사용하지 않았다.

## 3. 예측 가중치 선택

비교한 모델:

- `stock_model_a_usage_only_pred`: L1 사용량 모델
- `stock_model_a_usage_tweedie_pred`: Tweedie 사용량 모델
- `stock_model_d_module_c_pred`: Module C 특징 포함 Tweedie 모델

세 가중치가 1이 되는 5% 간격 조합 231개를 검증 WAPE로 비교했다. 글로벌 최적
가중치는 다음과 같으며, 등록되지 않은 수요유형의 fallback으로 사용한다.

| 모델 | 현행 | 글로벌 fallback |
|---|---:|---:|
| L1 | 1.00 | 0.20 |
| Tweedie | 0.00 | 0.50 |
| Module C Tweedie | 0.00 | 0.30 |

검증에서 수요유형별 가중치 라우터의 WAPE가 36.88%로 글로벌 혼합 36.97%보다
낮아 라우터를 선택했다.

| 수요유형 | L1 | Tweedie | Module C |
|---|---:|---:|---:|
| all_zero | 1.00 | 0.00 | 0.00 |
| erratic | 0.55 | 0.25 | 0.20 |
| insufficient_history | 0.15 | 0.40 | 0.45 |
| intermittent | 0.60 | 0.15 | 0.25 |
| lumpy | 0.25 | 0.00 | 0.75 |
| new_series | 0.35 | 0.15 | 0.50 |
| smooth | 0.15 | 0.50 | 0.35 |

`all_zero`에는 현행 L1을 그대로 유지했다. 새 이력과 smooth 수요는 Tweedie와
Module C 비중을 높였고, erratic·intermittent는 L1 비중을 더 보수적으로 유지했다.

## 4. 현재 정확도와 비교

최신 테스트 2025-10~12만 사용한 결과다.

| 지표 | 현행 L1 | 새 가중치 라우터 | 변화 |
|---|---:|---:|---:|
| WAPE | 39.0531% | 37.5788% | -1.4743%p |
| MAE | 54.9523 | 52.8778 | -3.78% |
| RMSE | 298.1661 | 201.9180 | -32.28% |
| Bias | -14.9849% | -6.3977% | 과소예측 8.5873%p 완화 |
| RMSLE | 0.7826 | 0.8120 | 악화 |
| MAPE | 79.0047% | 96.8024% | 악화 |
| SMAPE | 84.4852% | 85.3608% | 악화 |

WAPE를 선택 지표로 사용했으므로 전체 수량 오차와 큰 오차는 개선됐지만,
소량·0수요 인접 행에 민감한 MAPE·SMAPE·RMSLE는 좋아지지 않았다. 이 정책을
“모든 정확도 지표가 개선된 모델”로 표현하면 안 된다.

수요유형별 테스트 WAPE:

| 수요유형 | 현행 | 새 정책 | 변화 |
|---|---:|---:|---:|
| all_zero | 62.6479% | 62.6479% | 0.0000%p |
| erratic | 50.0907% | 49.8982% | -0.1926%p |
| insufficient_history | 45.9657% | 44.1965% | -1.7691%p |
| intermittent | 42.2342% | 41.8403% | -0.3939%p |
| lumpy | 55.0075% | 53.8999% | -1.1076%p |
| new_series | 55.5936% | 52.8381% | -2.7554%p |
| smooth | 35.0888% | 33.4137% | -1.6751%p |

최신 테스트에서 모든 수요유형의 WAPE가 개선되거나 동일했다. 이 결과는 선택
근거가 아니라 검증에서 이미 고정된 라우터의 사후 평가다.

## 5. 무역 가중치 수정

v1.3을 현행 기준으로 두고, 검증에서 선택된 후보 80%와 현행 20%를 혼합했다.

| 무역 위험요소 | v1.3 | v1.4 |
|---|---:|---:|
| 수입량 감소 | 0.108603 | 0.064146 |
| 순수입 가용량 감소 | 0.052991 | 0.033923 |
| 수입 중단 | 0.166239 | 0.194613 |
| 수입단가 상승 | 0.082981 | 0.051151 |
| 수입량 변동성 | 0.283601 | 0.375404 |
| 수입단가 변동성 | 0.063890 | 0.045012 |
| 공급국 집중 | 0.124644 | 0.135986 |
| 공급국 수 감소 | 0.034647 | 0.027795 |
| 순수입 노출 | 0.043747 | 0.039441 |
| 수출량 급증 | 0.038657 | 0.032529 |

임계값과 국가 커버리지 0.75는 학습기간에서 동일하게 재현돼 변경하지 않았다.
Module C 무역 overlay는 테스트를 제외한 학습+검증 위험분포로 계산해
`0.245 → 0.224`로 낮췄다.

품절 대리목표 테스트 결과:

| 지표 | 현행 v1.3 | v1.4 |
|---|---:|---:|
| 가중 MAE | 0.025726 | 0.025492 |
| Spearman | 0.189130 | 0.195333 |

MAE 개선은 0.91%로 작다. 이전 문서의 6.58%는 최종 테스트가 별도로 없던
학습/검증 구조의 수치이므로 이번 최신 테스트 결과와 동일하게 해석할 수 없다.

## 6. 현재 재고 출력 변화

새 가중치 라우터는 `outputs/stock_predictions.csv` 163,229행 전체에 적용했다.

| 항목 | 현행 L1 반사실 | 새 정책 | 변화 |
|---|---:|---:|---:|
| 예측사용량 혼합단위 합 | 15,836,473 | 17,980,568 | +13.54% |
| 목표재고 혼합단위 합 | 19,047,238 | 21,624,931 | +2,577,693 |

| 권고발주 혼합단위 합 | 277,049 | 524,952 | +247,904 |

목표재고는 123,049행에서 증가하고 11,599행에서 감소했다. 권고발주는 13,710행에서
증가하고 1,346행에서 감소했다. 품목별 단위가 다르므로 합계는 방향성 확인용이며
단일 물량 총계로 해석하지 않는다.

## 8. 재실행 순서

```bash
python -m src.trade.trade_weight_calibration --apply
python -m src.trade.trade_risk_scorer --provider csv
python -m src.module_c.pipeline
python -m src.feature_engineering
python -m src.modeling.training

# 모델별 예측 컬럼을 포함한 backtest 생성
python -m src.modeling.prediction

# 검증에서 가중치 선택, 최신 테스트 1회 평가, 정책 적용
python -m src.modeling.temporal_ensemble_tuning --apply

# 적용 정책으로 현재 예측 재생성
python -m src.modeling.prediction
```

신규 월이 3개월 이상 추가되면 시간창을 앞으로 이동해 다시 평가한다. 테스트 성능을
보고 이번 가중치를 사후 수정하면 현재 테스트가 다시 검증자료가 되므로, 다음
가중치 변경은 새로 들어오는 미래 월을 테스트로 남겨 진행해야 한다.
