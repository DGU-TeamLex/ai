# 데이터 계약 — 수요 정의와 재고 항등식

SSIS 원장(물품재고)의 입출고가 9종으로 세분돼 있어, 어느 컬럼을 수요로 볼지와
재고 수지가 어떻게 맞는지를 한 곳에 고정한다. 전처리·모델링 코드는 이 문서를 따른다.

관련 이슈: ai#40(순수요 정의), ai#42(항등식 정정), backend#64(검증 게이트)

---

## 1. 순수요 = `정상출고량`

**순수요는 `정상출고량` 하나다.** mu/sigma·수요예측·SS/ROP 산출은 모두 이 컬럼에서 출발한다.

| 컬럼 | 채움률 | 판단 |
|---|---|---|
| **정상출고량** | **100.0%** (2024~25 · 2018~19 공통) | **순수요로 사용** |
| 반납입고량 | 96.0% (99.99%가 0) | 반납은 사실상 미발생 → 보정 불필요 |
| 입고량 | 19.5% | 외부 구매 |
| 불출입고량 / 불출출고량 | 각 **0.02%** | 부서간 이동 기록이 거의 없음 → 이중계산 우려 불필요 |
| **자동폐기출고량** | 57.6% | **수요에서 제외** (§2 참조) |

이론적으로 우려되던 부서간 이동 이중계산은 실제 기록률이 0.02%로 무시할 수준이다.

### 자동폐기출고량을 수요에서 빼는 이유

`자동폐기출고량` 은 **재고 수지에 반영되지 않는 별도 정보 컬럼**이다(§2 검증).
이를 소비량에 포함하면 수요가 과대 추정되므로 순수요 산출에서 명시적으로 제외한다.

폐기 실적 자체는 재고유지 비용 계수를 실측 보정하는 데 쓸 수 있으므로,
수요와 분리해 **별도 지표**로 산출한다.

### 결측일 처리

원장은 거래가 있는 날만 행이 있는 희소 패널이다(관측 중앙값 11일 / 731일).

- **재고량**은 직전값을 유지(carry-forward)
- **출고량은 0으로 채움** — 채우지 않으면 mu 가 크게 과대해진다(실측 12.77 vs 1.95, 약 7.9배)

## 2. 재고 항등식

```
마감재고량 = 이전최종재고량
           + (입고량 + 불출입고량 + 반납입고량)
           − (불출출고량 + 정상출고량 + 반품출고량 + 폐기출고량 + 보정출고량)
```

**`자동폐기출고량` 은 이 식에 들어가지 않는다.**

### 검증 결과 (전량 재검증, 2026-07-28)

| 항등식 정의 | 2024~25 (16,263,091행) | 2018~19 (6,106,936행) |
|---|---|---|
| 자동폐기출고량 **차감** | 96.86% 일치 | 94.24% |
| **자동폐기출고량 제외** | **100.000% 일치** | **99.999% 일치** |

종전에 "항등식 불성립 3.14%(약 51만 행)"를 데이터 품질 문제로 보고했으나,
원인은 데이터 오류가 아니라 **항등식 정의 오류**였다. 원본 데이터 품질은
종전 평가보다 양호하며, 2018~19 기준 불일치는 610만 행 중 **68행**이다.

### 보조 근거

1. `자동폐기출고량` 은 **음수 499,180 / 양수 11,463** 으로 혼재한다(2024~25).
   실제 출고량이라면 나올 수 없는 분포다.
2. 정의서 v3 에서 **유일하게 컬럼 설명이 공란("-")** 이다 — 정보원 측도 정의를 특정하지 않았다.

## 3. 원본 파싱 주의

물품명·약품명 필드에 줄바꿈이 포함된 행이 있고 큰따옴표로 정상 인용돼 있다.
`split('|')` 로 읽으면 한 논리행이 2~3행으로 쪼개져 컬럼 수 불일치로 버려진다.

```python
csv.reader(f, delimiter="|", quotechar='"')   # 반드시 quotechar 지정
```

실측 유실 규모: 2018~19 **2,744행**, 2024~25 **2,511행**.
`quotechar` 를 지정하면 읽은 행수가 정의서 기재값과 정확히 일치한다
(2018~19 = 6,106,936). 같은 원인이 backend#66 으로 열려 있다.

인코딩은 **UTF-8** 이다(CP949 아님).

## 4. 컬럼 구성 차이 (기간별)

| 기간 | 컬럼 수 | 비고 |
|---|---|---|

| 2018~19 | **16** | `구입처코드`·`구입단가` 없음 |
