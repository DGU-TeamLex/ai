# 한국사회보장정보원 제출용 실험 결과표 양식

- 작성 원칙: 같은 실행의 입력·commit·기간·정책만 한 표에 사용
- 빈칸 표기: 확인하지 못한 값은 0이 아니라 `[실행 후 입력]` 또는 `해당 없음`으로 기록
