# 의료재고 예측 연구결과 종합

- 기준일: 2026-08-19
- 범위: 한국사회보장정보원 제공 데이터 기반 실험 연구
- 핵심 관점: 단일 최고성능 모형보다 데이터 통합·예측·외부위험·재고정책의 연결 가능성과 한계 검증

## 1. 연구가 해결하려 한 문제

원천 재고자료는 시기와 기관에 따라 품목명·규격·단위 표기가 달랐고, 반품·정정으로 보이는 음수
출고와 0수요가 많았다. 뉴스·원자재 자료도 재고품목과 직접 연결되는 공통키가 없었다. 따라서
다음 달 수요모형만 만드는 것으로는 과거자료와 외부위험을 일관되게 활용하거나 재고정책까지
설명하기 어려웠다.

본 연구는 다음 다섯 질문을 순서대로 검토했다.

1. 서로 다른 시기의 의료물품을 같은 분석축으로 정규화할 수 있는가?
2. 계층형 메타코드로 품목·원자재·위험을 추적 가능하게 연결할 수 있는가?
3. 현재 자료에서 어떤 수요예측 모형이 정확도와 편향 측면에서 유효한가?
4. 뉴스·원자재 신호가 수요예측을 안정적으로 개선하는가?
5. 외부위험을 공급차질 신호로 해석하면 재고정책이 어떻게 변하는가?

## 2. 연구 파이프라인

```text
원본 DAT·과거자료
→ 음수 원장값과 양수 모델수요 분리
→ 품목명·규격·단위 정규화
→ 표준품목·정의키·품목군·family·subtype 메타코드 생성
→ 2018~2019 품목의 strict·unique-core 연결과 미연결 격리
→ 원자재·공급위험·수요위험 메타코드 후보 생성
→ 별도 승인 매핑만 외부위험 연결에 사용
→ 시간순 수요예측 비교
→ 외부위험 수요효과 대조실험
→ 공급위험 기반 리드타임·안전재고·발주 민감도 실험
```

## 3. 데이터 정규화 연구결과

정규화는 수요량을 0~1로 바꾸는 작업이 아니다. Unicode·공백·기호·포장표기를 정리하고
품목명·규격·단위를 분리해 같은 품목인지 판별하는 표준화 과정이다. 실제 수요·재고·입고량은
원 단위를 유지했다.

| 지표 | 결과 | 해석 |
|---|---:|---|
| 전체 로컬 품목 매핑 | 585,279행 | 현재 409,519 + 과거 175,760 |
| 표준품목 | 125,557개 | 규격을 포함한 감사·추적 단위 |
| 의미정의 학습적격 매핑 | 556,276행 | 현재와 엄격 연결된 과거품목 |
| 과거 학습 연결 | 146,757/175,760개 | 83.50% |
| 과거 미연결 격리 | 29,003개 | 이름 임시키를 학습에 넣지 않음 |
| 기관·기간 로컬키 중복 | 0행 | 한 로컬품목이 복수 표준키로 갈라지는 오류 없음 |
| 표준키·정의키 누락 | 0행 | 감사키 완전성 게이트 통과 |
| 평균 연결 신뢰도 | 0.943 | 임시키 0.50을 포함한 평균 |

동일한 LightGBM L1 구조에서 엄격 연결된 과거자료를 사용했을 때 현재 재검증의 2025년 1~6월
검증 WAPE는 현재자료 전용 39.223%에서 과거자료 포함 37.246%로 **1.9769%p 낮아졌다**.
가중치 1.0은 이 검증구간에서만 선택했고 시험구간은 선택에 사용하지 않았다. 2026-07-29의
이전 실행은 0.8106%p 개선이었지만, 데이터·평가계약을 다시 고정한 현재 산출물을 최종 근거로
사용한다. 이는 과거자료 전체가 자동으로 유효하다는 뜻이 아니라 정규화와 연결 게이트를 통과한
자료가 학습에 기여했다는 결과다.

## 4. 메타코드 연구결과

메타코드는 과거품목·현재품목·외부위험·재고정책을 연결하는 공통 언어다.

| 계층 | 주요 코드 | 역할 |
|---|---|---|
| 물리 재고 | `local_item_key`, `stock_item_key` | 기관·부서·로컬코드의 실제 재고경계 보존 |
| 표준품목 | `standard_item_key`, `standard_item_definition_key` | 표준품목과 규격·단위 의미 추적 |
| 품목분류 | `standard_item_group_id`, `standard_item_family_id`, `standard_item_subtype_id` | 품목군·계열·세부유형 분석 |
| 원자재 | `raw_material_meta_code` | PP·금속·API 등 원자재 후보 연결 |
| 공급위험 | `raw_material_risk_meta_code` | 원자재 공급차질 유형 연결 |
| 수요위험 | `demand_risk_meta_code` | 감염병·재난·정책확대 등 수요사건 연결 |

통합 분류 산출물에는 대표품목 101,546행이 있다. 이 중 특정 family가 부여된 행은 57,591행
(56.71%), subtype 20,597행, 규격 7,337행, 단위 14,952행이다. 원자재 메타코드 후보 중
구체적 코드가 있는 행은 58,103행(57.22%)이다.

그러나 이 수치를 승인 완료로 해석하면 안 된다. family 외부근거 검증은 1,176행뿐이며
분류 검토가 필요한 행은 100,370행이다. 통합 원자재 후보 101,546행도 모두 `needs_review`다.
실제 PP 실험에는 이 후보 전체를 쓰지 않고 별도 엄격 승인 규칙을 통과한 2,212개 후보와
2,297개 재고품목키만 사용했다. 승인된 재고 매핑은 현재 모두 `POLYPROPYLENE_PP`의
`direct_component` 관계다.

따라서 메타코드의 연구 기여는 인과관계를 증명한 것이 아니라, 어떤 자료가 후보이고 어떤 자료가
승인됐는지를 구분하면서 이질적인 자료를 연결·감사할 수 있게 만든 데 있다.

## 5. 수요예측 연구결과

| 역할 | 모형 | WAPE | BIAS | 해석 |
|---|---|---:|---:|---|
| 전체 연구 주모형 | 수요전용 L1 | 35.714% | -9.617% | 정확도 우세, 과소예측 큼 |
| 편향 대안 | Tweedie | 37.272% | -1.971% | WAPE 희생, 편향 우세 |
| 재고정책 도전모형 | 고정 L1 50% + Tweedie 50% | 36.180% | -3.920% | 재사용 평가, 신규 월 확인 전 미적용 |

결과는 하나의 모형이 모든 목적에서 우월하지 않음을 보여준다. L1은 전체 절대오차가 가장 작지만
재고 관점에서는 과소예측 위험이 있다. 고정 50:50은 일부 WAPE를 희생해 편향과 미충족 수요를
줄이는 후보이며 수요예측 대표모형과 역할을 분리해야 한다.

## 6. 뉴스·원자재 연구결과

외부위험을 수요예측 특성으로 직접 넣었을 때 원자재 모형의 전체 WAPE는 사용량 전용 기준보다
0.101%p 낮았으나 BIAS는 악화됐다. 뉴스와 뉴스+원자재 결합은 통계적으로 안정적인 개선이
아니었다. 주사기–PP 내 원자재 위험과 다음 달 수요의 상관도 0.012로 사실상 없었다.

따라서 `원자재 가격 상승 → 의료소모품 사용량 증가`라는 경로는 채택하지 않았다. 이는 실패한
실험을 숨긴 것이 아니라 외부위험의 역할을 수요효과와 공급효과로 분리한 연구결과다.

## 7. 공급위험과 재고정책 연구결과

PP 가격·변동성은 수요량에 더하지 않고 공급차질 위험으로 해석했다. 30일은 전체 품목의 최종
리드타임 예측값이 아니라 계약자료 기반 기본·통제값이다.

```text
PP 공급위험 Rpp = PP 가격위험 × 0.35 / 0.45
유효 리드타임 Leff = 30 + 29Rpp
제안발주량 Q = max(목표재고 - 재고포지션, 0)
```

| 지표 | 기본 | PP 병렬값 | 변화 |
|---|---:|---:|---:|
| 평균 유효 리드타임 | 30.00일 | 34.19일 | +4.19일 |
| 안전재고 합계 | 29,727.32 | 34,707.91 | +16.75% |
| 목표재고 합계 | 98,991.65 | 108,763.79 | +9.87% |
| 품질 게이트 후 제안발주량 | 5,574.20 | 6,783.13 | +21.69% |

이 값은 실제 공급차질의 인과효과가 아니라 정책 민감도다. 실제 주문일·약속일·입고일·부분입고·
결품원인이 없으므로 품절감소를 증명하거나 모든 품목에 일반화하지 않는다.

## 8. 종합 연구 기여

1. **데이터 기여:** 시기·기관별 이질적인 품목을 원 단위를 보존한 채 정규화했다.
2. **연결 기여:** 표준품목과 계층형 메타코드로 과거자료·원자재·위험을 추적 가능한 구조로 만들었다.
3. **품질관리 기여:** 후보 메타코드와 승인 매핑을 분리하고 미연결·휴면·오래된 자료를 자동 계산에서 차단했다.
4. **모형 기여:** WAPE 정확도와 과소예측 편향이 충돌한다는 점을 동일 평가계약에서 확인했다.
5. **부정적 결과:** 뉴스·원자재가 사용수요를 안정적으로 개선한다는 근거가 부족함을 확인했다.
6. **정책 기여:** 외부위험을 공급위험으로 재해석해 리드타임·안전재고·발주량으로 연결했다.

## 9. 주장 가능한 범위와 한계

| 주장 가능 | 아직 주장 불가 |
|---|---|
| 정규화된 과거품목 83.50%를 현재 분석축에 연결 | 모든 과거품목이 같은 실물품목이라는 주장 |
| 표준키 누락·중복 없이 재현 가능한 매핑 생성 | 후보 메타코드 전체의 전문가 승인 완료 |
| L1의 낮은 WAPE와 큰 음의 BIAS 확인 | 고정 50:50의 신규기간 우월성 |
| 수요효과와 공급효과를 분리한 외부위험 실험 | PP 가격이 실제 납기지연·품절을 유발했다는 인과 주장 |
| 공급위험 변화에 따른 재고정책 민감도 | 경제적으로 최적인 실제 발주량 |

## 10. 최종 결론

본 연구의 최종 성과는 단일 최적모형의 확정만이 아니다. 품목 정규화와 계층형 메타코드를 통해
과거자료·현재품목·외부위험을 공통 분석축으로 연결하고, 수요예측에서 재고정책까지 이어지는
재현 가능한 연구 파이프라인을 구축했다. 수요전용 L1은 WAPE가 가장 낮지만 과소예측 편향이
확인됐고, 고정 50:50은 정확도와 부족위험 사이의 교환관계를 보여주는 도전모형이다. 뉴스·원자재의
수요효과는 안정적이지 않았으나, 원자재 위험을 공급차질 신호로 재해석하면 리드타임·안전재고·
발주량의 민감도를 설명할 수 있었다.

따라서 이 연구는 `데이터 정규화 → 메타코드 연결 → 수요예측 비교 → 외부위험 역할 검증 →
재고정책 민감도`의 전체 흐름과 각 단계의 주장 한계를 함께 제시한 연구로 종합한다.
