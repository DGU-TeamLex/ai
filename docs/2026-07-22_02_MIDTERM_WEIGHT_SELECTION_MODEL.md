# 중간점검 2. 위험 가중치 선정 모델

작성일: 2026-07-22
발표일: 2026-07-23

## 1. 발표용 한 문장

뉴스와 원자재 가격을 수요위험과 공급위험으로 분리한 뒤, 승인된 관계만 통과시키고
정규화된 위험 신호를 제한된 가중합으로 변환한다.

## 2. 현재 모델의 정확한 성격

현재 가중치는 데이터로 학습한 인과계수가 아니다. 설정 파일의 상태도 다음과 같이
명시돼 있다.

```text
version = module-c-v1.0
calibration_status = policy_seed_requires_backtest
coefficient_basis = initial_policy_bounds_not_empirical_causal_estimates
```

따라서 발표에서는 `학습 완료된 최적 가중치`가 아니라 `백테스트 전 정책 초기 가중치`라고
설명해야 한다. 외부 위험 학습열에 0이 아닌 승인 신호가 없어 뉴스·원자재 결합 모델은
현재 학습에서 제외됐다.

## 3. 두 개의 위험축

```text
뉴스 -> 질병/사건 -> 의료용품 수요위험
뉴스/선물·지표가격 -> 원자재 -> 의료용품 공급위험
```

수요위험은 예상 사용량을 바꾸고, 공급위험은 조달 리드타임과 안전재고를 바꾼다. 두 값을
처음부터 하나로 더하면 같은 사건이 중복 반영될 수 있어 별도 축으로 유지한다.

## 4. 원자재 시장위험 내부 가중치

시장 시계열에서 다음 세 특성을 0~1로 정규화한다.

```text
return_risk
  = clip(max(return_30d, 0) / 0.20, 0, 1)

volatility_risk
  = clip(max(volatility_30d, 0) / 0.12, 0, 1)

price_level_risk
  = clip(max(price_vs_90d_mean, 0) / 0.15, 0, 1)
```

정규화한 시장요인을 다음 가중치로 결합한다.

```text
market_factor_risk
  = 0.45 * return_risk
  + 0.30 * volatility_risk
  + 0.25 * price_level_risk
```

| 시장요인 | 가중치 | 초기 판단 |
|---|---:|---|
| 30일 상승률 | 0.45 | 단기 가격충격을 가장 직접적으로 반영 |
| 30일 변동성 | 0.30 | 공급 불확실성 반영 |
| 90일 평균 대비 가격 | 0.25 | 가격 수준의 지속적 이탈 반영 |

## 5. 공급위험 최종 가중치

```text
supply_risk
  = 0.45 * supply_news_risk
  + 0.20 * material_news_risk
  + 0.35 * market_price_risk

total_risk
  = max(demand_risk, supply_risk)
```

| 공급 신호 | 가중치 | 초기 판단 |
|---|---:|---|
| 공급차질 뉴스 | 0.45 | 공장중단, 수출제한, 물류차질처럼 직접적인 공급 사건 |
| 원자재 언급 뉴스 | 0.20 | 직접 공급차질보다 불확실성이 커 보조 신호로 사용 |
| 시장가격 위험 | 0.35 | 수치화 가능하지만 의료용품까지의 전파 지연을 고려 |

각 가중치 묶음은 음수가 아니고 합이 정확히 1이 되도록 코드에서 검증한다.

## 6. 승인 게이트

가중치보다 먼저 적용되는 조건이 승인 게이트다.

```text
approved disease-item relation == false -> demand risk = 0
approved item-material relation == false -> supply/material/price risk = 0
```

원신호가 0.9처럼 높더라도 품목과 사건 또는 원자재의 관계가 검수되지 않았으면 재고량을
바꾸지 않는다. 이는 할루시네이션과 오매핑이 자동발주로 전파되는 것을 막는 핵심 규칙이다.

`is_synthetic_signal=true`, `operational_use_allowed=false`가 명시돼 있다.

## 9. 왜 이 방식으로 시작했는가

1. 수요와 공급을 분리해 재고 처방의 이유를 설명할 수 있다.
2. 모든 점수를 0~1 범위로 제한해 서로 다른 외부 API를 결합할 수 있다.
3. 가중치 합을 1로 고정해 기여도를 감사할 수 있다.
4. 승인 관계가 없으면 0으로 만들어 오매핑의 영향 범위를 차단한다.
5. 최종 재고 버퍼에 별도 상한을 둬 정책 초기값의 과잉 반응을 제한한다.

## 10. 데이터 기반 가중치로 바꾸는 절차

운영 이력이 쌓이면 다음 목적함수로 가중치를 보정한다.

```text
loss
  = lambda_1 * stockout_cost
  + lambda_2 * overstock_cost
  + lambda_3 * order_volatility
```

진행 순서는 다음과 같다.

1. 공급지연, 품절, 뉴스 사건, 가격충격의 발생일을 동일 시간축에 맞춘다.
2. 승인된 품목-원자재-시장요인 경로만 학습 표본으로 사용한다.
3. 시간순 walk-forward 구간에서 제한조건이 있는 grid search 또는 Bayesian optimization을 수행한다.
4. 가중치가 음수가 아니고 각 묶음의 합이 1이 되게 제한한다.
5. 결품 감소와 과잉재고 증가를 함께 비교한다.
6. 기관·품목군별 안정성을 확인한 뒤 정책 버전을 올린다.
