# 논문에 근거한 잔차 학습과 과거 자료 비중 실험

## 목적과 근거의 범위

일별 출고 변수를 추가한 모델은 평가 WAPE 34.7678%, BIAS -6.6705%였다. 이번에는 같은 74개 입력 변수를 유지하고, 다음 달 사용량 자체 대신 과거 평균에서 얼마나 달라지는지 학습한다. 새 외부 자료나 평가 집단 축소 없이 모델 표현 방식을 비교한다.

Zhang(2003)은 통계 모형과 신경망을 결합한 시계열 예측을 연구했다. Smyl(2020)은 지수평활과 순환신경망을 함께 사용하는 방법을 제시했다. 이들은 통계적 기본 구조와 학습 모형을 결합하는 설계의 근거지만, 최근 3개월 평균과 LightGBM의 조합이 더 좋다는 직접 증거는 아니다. 이번 구현은 두 논문의 알고리즘 재현이 아니라 이 원칙을 바탕으로 한 별도 실험이다.[1][2]

잔차는 관측값과 기본 예측의 차이다. 기본 모형을 전체 기간으로 적합하면 잔차에 미래 정보가 개입할 수 있으므로, 이번 기본값은 학습된 별도 모델이 아니라 예측 시점까지의 최근 3개월 평균으로 고정한다. 실제 기록이 짧으면 기존 특징표에서 산출한 가용 연속 기록 평균을 사용한다. 결측이나 음수 기본값이면 중단한다.[3]

## 공식

품목 i의 예측 시점 t에 알려진 최근 평균을 b(i,t), 다음 달 실제 사용량을 y(i,t+1), 알려진 입력을 x(i,t)라 한다.

`잔차 r(i,t+1) = y(i,t+1) - b(i,t)`

`최종 예측 = max(0, b(i,t) + g(x(i,t)))`

g는 잔차를 예측하는 LightGBM이다. 잔차 자체는 음수일 수 있으므로 학습 전 0으로 자르지 않는다. 기본값을 더한 최종 수량만 0 이상으로 제한한다. 예를 들어 기본값 40,000, 보정값 -3,000이면 예측은 37,000이다.

L1 목적은 `Σ w × |r - g(x)|`다. 최종 0 제한 전에는 `|r-g| = |y-(b+g)|`이므로 수량 단위의 절대오차라는 목적을 유지한다. 목표를 로그나 비율로 바꿔 큰 수량 오차의 중요도를 몰래 바꾸지 않는다. 고정된 트리 용량에서 과거 규모를 기본값으로 유지하는 표현이 도움이 되는지 시험하는 것이다. 무한한 표현력을 가진 모형에서는 단순한 재표현이므로 원리상 항상 유리하다는 주장은 하지 않는다.

조기 종료는 잔차 점수가 아닌, 기본값을 더하고 0 이상으로 복원한 수량의 MAE로 결정한다. 검증 집단의 분모가 고정돼 있으므로 이 기준은 WAPE 순위와 일치한다.

## 비교 후보

- direct_full: 다음 달 수량 직접 학습, 과거 자료 비중 1.
- residual_full: 최근 평균 대비 잔차 학습, 과거 자료 비중 1.
- residual_quarter: 잔차 방식 유지, 2018~2019년 자료 비중 0.25.
- residual_recent: 잔차 방식 유지, 2018~2019년 자료 제외.

첫 두 후보로 잔차 표현의 효과를 비교한다. 뒤의 두 후보는 residual_full과 비교해 과거 자료 비중의 효과를 본다. 직접 학습 방식의 과거 비중 변경까지 포함한 완전한 교차 실험은 아니므로 상호작용 전체를 검증했다고 주장하지 않는다.

Kuznetsov와 Mohri(2015)는 시간이 지나며 분포가 달라지는 시계열의 학습을 다룬다. 이번에 확인한 과거·최근 자료의 사용량 0 비율 차이는 비중을 비교할 동기이며, 그 차이만으로 과거 자료를 버려야 한다는 결론은 아니다. 0.25는 논문이 권고한 숫자가 아니라 사전에 정한 실험 후보다. 해당 논문의 discrepancy 추정 알고리즘을 구현한 것도 아니다.[4]

최근 자료의 상대 비중은 1이다. 최적화에서 전체 가중치 규모가 규제에 주는 영향을 줄이기 위해 학습 가중치 평균을 1로 정규화한다. 과거 비중이 0이면 해당 행은 결측 대체값과 범주 목록을 학습하기 전부터 제외한다. 과거 자료는 기존 historical_training_eligible 조건을 충족한 행만 사용한다.

## 평가와 자원

후보마다 5~6월 및 8~9월 검증을 별도로 수행해 총 8회 순차 학습한다. 원본을 다시 읽지 않고 이미 정합성 검사를 통과한 daily_features_v1/prepared.parquet를 복사하며 SHA256으로 동일성을 확인한다. 전체 학습 자료를 사용한다. 표본 축소나 큰 오차 행 제외는 없다.

두 검증 구간의 절대오차 합/실제량 합으로 최종 후보를 선택해 먼저 저장한다. 이후 직접 학습 대조군과 선택 후보만 10~12월에서 평가한다. BIAS와 월별 성능도 함께 보고한다. WAPE가 줄어도 과소예측이 남으면 자동 발주에 적합하다고 주장하지 않는다.

10~12월은 이미 반복 사용했고 잔차 실험의 가설 형성에도 영향을 주었다. 따라서 독립적인 최종 검증이 아니며 향후 새로운 기간 자료가 필요하다. 이번 후보 비교로 효과가 없으면 없다고 보고한다.

CPU 2개, BLAS 스레드 1개, 순차 학습, 작업별 2시간 제한과 가용 RAM 1.5GiB 미만 중단을 유지한다. 모델별 완료 체크포인트를 보존하고 실패 시 자동 재실행하지 않는다. 서비스 모델과 main/dev에는 반영하지 않는다.

이 브랜치의 실행 문서는 본 문서가 이전 입력 변수 실험 안내보다 우선한다. 출력은 outputs/residual_demand_v1의 status.json, manifest.json, 모델별 JSON/pkl, selection.json, test_results.json, 결과요약.md다. 실행 명령은 이전과 동일한 suite 진입점에 원래 작업트리 --source, family_search_v1/evaluation.parquet --reference, 새 --output을 지정한다.

## 참고문헌과 실제 확인 범위

1. G. Peter Zhang (2003), *Time series forecasting using a hybrid ARIMA and neural network model*, Neurocomputing 50, 159–175. [DOI](https://doi.org/10.1016/S0925-2312(01)00702-0). 출판사 검색 결과의 공개 소개를 확인했다. 본문 직접 열기는 차단되어 전체 공식이나 결과를 열람했다고 주장하지 않는다.
2. Slawek Smyl (2020), *A hybrid method of exponential smoothing and recurrent neural networks for time series forecasting*, International Journal of Forecasting 36(1), 75–85. [DOI](https://doi.org/10.1016/j.ijforecast.2019.03.017). 공개 초록의 지수평활·신경망 결합 원칙을 참고했다. 본문 직접 열기는 차단됐고 이번 구현은 ES-RNN 재현이 아니다.
3. Hyndman & Athanasopoulos, *Forecasting: Principles and Practice*, §5.3. [Fitted values and residuals](https://otexts.com/fpp3/residuals.html). 잔차와 실제 예측오차의 구분 및 미래 자료를 포함한 적합값의 위험을 확인했다.
4. Vitaly Kuznetsov & Mehryar Mohri (2015), *Learning Theory and Algorithms for Forecasting Non-stationary Time Series*, NeurIPS 28. [학회 원문 페이지](https://proceedings.neurips.cc/paper/2015/hash/41f1f19176d383480afa65d325c06ed0-Abstract.html). 학회 초록의 비정상 시계열·분포 차이 기반 학습 원칙을 참고했다. 본 실험의 가중치나 효과에 대한 직접 보장은 아니다.

현재 일별 정보 모델의 전체 평가 WAPE는 34.7678%다. 같은 예측에서 정의 키가 DEF::로 시작하고 UNRESOLVED를 포함하지 않는 327,576건은 34.5740%다. UNSPECIFIED까지 없는 90,779건은 34.6096%다. 이는 문자열 기준의 상세도 구분일 뿐 전문 검수 통과를 보장하지 않는다. 해당 품목만 따로 재학습한 결과도 아니다. 따라서 전체 점수가 미정의 품목 때문에만 높다고 설명할 근거는 없다.
