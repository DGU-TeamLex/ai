# 대체 모델 탐색: HistGradientBoosting

기존 74변수 LightGBM 직접 예측 모델은 변경하지 않고 비교 기준으로 보존한다. 재사용 2025년 10~12월 WAPE 34.734137%, BIAS -6.632005%다.

이전 CatBoost·XGBoost·여러 시계열 신경망 실험을 확인했다. 이번 후보는 scikit-learn HistGradientBoostingRegressor다. 별도 모델 구현이지만 LightGBM과 같은 트리 부스팅 계열이므로 완전히 다른 구조라고 주장하지 않는다. 기존 수요 예측 실험에는 이 구현을 사용하지 않았다. 프로젝트의 리드타임 코드에는 동명 회귀기가 있으나 다른 예측 과제다.

## 고정한 비교 조건

- 동일한 74개 원본 변수와 전체 적격 학습 행을 사용한다.
- direct: 원래 수량을 절대오차 손실로 학습한다.
- scaled: 예측 시점 과거 3개월 평균을 최소 1로 제한한 s로 정답을 나누고, 가중치를 s로 준다. 예측은 s를 곱해 원래 수량으로 복원한다. s×|y/s-p|=|y-sp|이므로 표본별 원래 단위 절대오차와 대응한다. 정답을 바꾸거나 작은 품목만 유리하게 평가하지 않는다.
- 최대 1,200회, 잎 63개, 최소 잎 표본 50개, 학습률 0.05, L2 규제 1, 조기 종료 75회로 고정한다.
- 2025년 4월까지 학습→5~6월 검증, 7월까지 학습→8~9월 검증. 두 구간 합산 WAPE로 후보 선택을 먼저 저장한 후 재사용 10~12월을 비교한다.
- 미래 정답을 범주 인코딩에 사용하지 않는다. 범주 수 제한 때문에 학습 빈도 상위 253개+기타로 표현하고, 학습 자료 내 등장 비율을 함께 추가한다. 따라서 원본 정보는 같아도 LightGBM과 입력 표현이 완전히 같지는 않다. 범주 정체성 일부를 잃을 수 있는 한계를 명시한다.
- 기존 정답·전체 품목·기간을 고정하고 WAPE, BIAS, 월별 결과를 기록한다. 두 검증 기간과 평가 기간 모두 개발에 재사용됐으므로 독립 확증으로 표현하지 않는다.

공식 API의 외부 검증 입력과 절대오차 손실을 사용한다. 실행 환경 scikit-learn 1.7.2에서 fit의 X_val, y_val, sample_weight_val을 직접 확인하고 소규모 통합 테스트를 수행한다. 참고: [HistGradientBoostingRegressor 공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html).

## 안전 및 종료

4개 학습을 2스레드로 순차 실행하며 BLAS는 1스레드다. 단계별 모델과 로그를 남긴다. 여유 메모리 1.5GiB 미만 또는 단계당 2시간 초과 시 본 실험 자식만 중단한다. 전원·발열 안전을 보장하는 제한은 아니다. 자동 재실행하지 않으며 원본과 기존 모델·결과를 덮어쓰지 않는다.

실행 위치는 이 작업 폴더의 outputs/histboost_v1. results.json에 기존 대비 개선 수치가 나온 뒤에만 개선 여부를 판단한다. 실패한 설정의 무한 튜닝은 하지 않는다. 이 후보의 결과를 근거로 다른 계열 탐색 필요성을 다시 판단하고, 서비스 모델 교체는 하지 않는다.
