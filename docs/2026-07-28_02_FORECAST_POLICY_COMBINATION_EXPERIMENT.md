# 예측·안전재고 조합 실험 결과

## 1. 결론

현재 데이터에서 사용량 예측의 최적 후보는 **수요유형별 라우터**다. 2025년 8~9월만
사용해 모델을 선택하고, 선택에 사용하지 않은 10~12월에서 WAPE **37.58%**를 기록했다.

90% 서비스수준의 1개월 수요충족 대리지표에서는 **Module C Tweedie 예측 + 수요유형·
예측규모별 경험적 오차분위수 버퍼**가 가장 낮은 pinball loss를 기록했다. 다만 목표량이
실수요의 1.576배이므로 실제 리드타임·보유비용·유효기간 자료 없이 자동발주에 적용하지
않는다.

## 2. 누수 방지

| 구분 | 기간 | 용도 |
|---|---|---|
| 조합 선택·오차분포 보정 | 2025-08~2025-09 | 라우터와 버퍼 산정 |
| 최종 평가 | 2025-10~2025-12 | 선택 후 한 번만 평가 |

전체기간으로 계산된 `mu_corrected`는 2025-12까지의 관측을 포함하므로 홀드아웃 순위에서
제외했다. 또한 기관×품목 값이어서 기관×부서×품목 예측에 그대로 결합하면 부서별로
중복된다.

## 3. 비교 대상

### 사용량 예측

- 최근값·3/6개월 평균·3개월 중앙값·전년동월·확장평균
- LightGBM L1
- LightGBM Tweedie
- Module C 피처를 포함한 Tweedie
- L1·Tweedie 25/50/75% 혼합
- 수요 발생확률×양수 수요크기 계층 베이지안 모멘트 추정형
- 보정기간에서 선택한 수요유형별 라우터

계층 베이지안 후보는 논문의 완전한 marginal-likelihood 최적화 구현이 아니다. 현재
데이터에서 계산 가능한 충분통계와 모멘트 추정으로 하이퍼파라미터를 구한 challenger다.
작은 `수요유형×item_group` pool은 수요유형 pool로 후퇴한다.

### 재고 버퍼

- 버퍼 없음
- 예측량의 20%: 현재 고정률 방식
- 보정기간 오차의 정규근사 분위수
- 보정기간 오차의 경험적 분위수

오차는 수요유형과 예측규모 구간별로 pooling했다. 목표값은 다음 1개월 대리식이다.

```text
target_proxy = point_forecast + max(error_quantile, 0)
```

## 4. 사용량 예측 결과

| 평가기간 순위 | 방식 | WAPE | Bias |
|---:|---|---:|---:|
| 1 | 수요유형별 라우터 | **37.58%** | -5.13% |
| 2 | L1 25% + Tweedie 75% | 37.71% | -6.47% |
| 3 | Module C Tweedie | 37.78% | -3.33% |
| 4 | Tweedie | 37.89% | -3.63% |
| 5 | L1 | 39.05% | -14.98% |
| - | 계층모델: 수요유형×품목군 | 45.76% | -2.32% |
| - | 계층모델: 수요유형 | 46.05% | -1.52% |

라우터는 다음과 같이 선택됐다.

| 수요유형 | 선택 방식 |
|---|---|
| all_zero | 직전월 |
| erratic | L1 50% + Tweedie 50% |
| insufficient_history | L1 25% + Tweedie 75% |
| intermittent | L1 50% + Tweedie 50% |
| lumpy | L1 25% + Tweedie 75% |
| new_series | L1 25% + Tweedie 75% |
| smooth | Module C Tweedie |

라우터는 L1 대비 WAPE를 1.47%p 낮췄지만 Module C 대비 개선은 0.19%p다. 평가월이
3개뿐이므로 champion을 즉시 교체하기보다 challenger로 유지한다.

## 5. 90% 서비스수준

| 방식 | Pinball loss | 양수행 충족률 | 단위 Fill rate | 목표/실수요 |
|---|---:|---:|---:|---:|
| Module C + 경험적 분위수 | **18.20** | 89.64% | 92.83% | 1.576 |
| Tweedie + 경험적 분위수 | 18.22 | 89.66% | 92.82% | 1.576 |
| 라우터 + 경험적 분위수 | 18.50 | 89.66% | 92.67% | 1.582 |
| Module C + 정규 분위수 | 20.02 | 94.39% | 95.09% | 1.932 |
| Module C + 고정 20% | 21.06 | 71.22% | 86.63% | 1.160 |
| 현재 target_stock | 27.59 | 61.77% | 80.61% | 1.021 |

선택 조합은 현재 `target_stock` 대비 pinball loss를 34.03% 낮추고, 양수행 충족률을
27.87%p, 단위 fill rate를 12.22%p 높였다. 대신 목표/실수요 비율은 54.35% 증가했다.
즉, 품절 방어는 좋아지지만 보유량 비용도 크게 늘어나는 조합이다.

## 6. 95% 민감도

95% 조합선택 구간에서는 Module C + 경험적 분위수가 선택됐고, 미사용 평가 구간에서
pinball loss 13.29, 양수행 충족률 94.54%, fill rate 95.21%, 목표/실수요 1.930을
기록했다. 평가 구간만 사후 정렬하면 Tweedie 조합이 13.27로 근소하게 낮지만, 이는
선택 규칙에 사용하지 않는다. 높은 서비스수준을 일괄 적용하기보다 필수의약품·대체불가
품목에만 제한해야 한다.

## 7. 해석과 보류 항목

1. TSB-HB 모멘트 추정형은 현재 데이터에서 선택되지 않았다. 짧은 이력과 관측 공백,
   월 단위 집계에서 occurrence-size 분리의 이점이 충분하지 않았다.
2. Robbins 포아송 방식은 서로 다른 관측기간, 묶음 출고, 절단수요 때문에 제외했다.
3. GARCH는 예측오차가 5개월뿐이어서 품목별 분산모델을 식별할 수 없어 제외했다.
4. 결과는 월 수요충족 대리지표다. 실제 조달 리드타임 동안의 재고 시뮬레이션이 아니다.
5. 일괄 승인 taxonomy에는 낮은 근거의 분류도 포함되므로 계층 pooling 결과를 운영
   승인 근거로 사용하지 않는다.

## 8. 다음 적용 순서

1. 라우터를 challenger로 저장하고 신규 3개월 이상 shadow 평가한다.
2. 발주일·입고일로 실제 리드타임과 지연분포를 만든다.
3. `mu_corrected`를 각 forecast origin 기준으로 다시 계산해 누수 없는 후보를 만든다.
4. 월 수요가 아니라 리드타임 수요오차로 경험적 분위수를 재산정한다.
5. CSL, fill rate, 평균재고, 폐기·유효기간, backorder 비용으로 정책을 다시 선택한다.
