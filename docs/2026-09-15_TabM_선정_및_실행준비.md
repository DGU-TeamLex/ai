# 다음 대체 모델: TabM

## 선정 근거

HGB는 직접 수량과 규모 정규화 모두 기존 LightGBM보다 나빴다. 추가 트리 설정을 무작정 반복하지 않고, 표 형태의 입력을 직접 처리하는 신경망 TabM을 다음 후보로 선정한다.

TabM은 여러 MLP 예측기를 공유 가중치로 함께 학습하는 구조다. ICLR 2025 논문과 저자 공식 구현을 확인했다. 기존에 실행한 단변량 시계열 신경망과 달리 현재 기관·품목 분류·과거 재고·사용 패턴 등의 표 형태 변수를 직접 입력하는 비교를 계획한다. 논문의 공개 데이터 성능은 우리 의료재고 데이터 성능을 보장하지 않는다.

- [공식 논문](https://proceedings.iclr.cc/paper_files/paper/2025/hash/c1ba41c694834aeef91ae161711d4939-Abstract-Conference.html)
- [저자 공식 구현과 학습 지침](https://github.com/yandex-research/tabm)

공식 구현은 학습 때 여러 출력의 평균을 먼저 구해 손실을 계산하지 말고, 각 출력의 손실을 계산한 뒤 평균하도록 안내한다. 추론 시에는 출력을 평균한다. 이를 지켜야 단순 MLP 평균과 다른 구현을 유지할 수 있다.

## 실행 환경 점검

기존 model-family-search-20260913 환경의 PyTorch 2.11.0+cu128을 읽기 전용으로 사용한다. 해당 환경에는 pip가 없어서 다른 기존 pip로 신규 작업 폴더 outputs/tabm_runtime에만 tabm 0.0.3 및 rtdl_num_embeddings 0.0.12를 --no-deps 설치했다. 기존 패키지는 업그레이드하지 않았다.

CPU 2스레드에서 입력 512×74, 출력 512×4×1의 전방·역방향 계산을 확인했다. 이 점검은 합성 텐서를 이용한 API 호환성 검사다. 실제 데이터 학습, 성능 실험, 장시간 부하 검사, GPU 안정성 검사가 아니다. 실제 WAPE 결과로 보고하지 않는다. 코드 scripts/probe_tabm.py로 재현할 수 있다.

## 다음 실제 실험 설계

기준 모델은 74변수 LightGBM 파일을 그대로 보존한다. 첫 TabM은 같은 74개 원본 변수로 전체 적격 데이터를 학습하고, 범주 변환·수치 정규화는 학습 기간에만 맞춘다. 과거 검증 두 구간에서 먼저 선택하고, 재사용 10~12월을 선택 이후에 비교한다. 손실은 원래 수량 단위 절대오차와 대응하도록 하고, 여러 모델 출력을 평균하는 추론 규칙까지 검증한다. CPU 2스레드·순차 실행·체크포인트를 사용하고 장시간 실행 전 실제 배치의 메모리와 시간을 확인한다. GPU는 이번에 사용하지 않는다.

합성 호환성 점검용 폭128·블록2·출력4는 논문 최적 설정이 아니다. 실제 실험 설정과 epoch 상한·조기 종료·자원 중단 조건은 실행 코드와 계획에 먼저 고정한다. 단일 부적절한 설정이 실패했다고 TabM 계열 전체를 배제하지는 않되 평가 기간을 보고 무한 튜닝하지 않는다.

공백 이전 관측 정보는 첫 TabM과 동시에 섞지 않는다. 해당 정보가 연결된 검증 40,617행은 기존 전체 절대오차의 11.7242%를 차지하며, 그 표본만 완벽히 맞히는 상한에서도 전체 검증 WAPE는 31.3272%다. 이는 해당 변수만으로 25%에 도달할 수 없음을 뜻한다. 전체 재학습의 다른 표본에 대한 간접 효과까지 제한하는 수학적 상한은 아니며 실제 개선률도 아니다. 후보 모델 자체의 효과를 먼저 분리해 확인한 후 추가 변수의 우선순위를 결정한다.

## 실제 학습 사전 고정 조건

`scripts/train_tabm.py`로 전체 적격 자료를 학습한다. 첫 구간은 2025년 4월 예측 대상까지 학습하고 5~6월에 검증한다. 다음 구간은 7월까지 학습하고 8~9월에 검증한다. 2018~2019년 자료의 기존 적격 여부를 그대로 따른다. 원본 74변수와 정답을 변경하지 않으며, 공백 이전 정보나 약성분을 추가하지 않는다.

수치 변수는 부호를 보존한 log(1+절댓값) 변환 후 학습 자료에서 구한 평균과 표준편차로 정규화한다. 누락 여부를 별도로 입력한다. 범주 변수는 학습 자료에 있는 값만 사전을 만들고 각각 8차원으로 표현한다. 학습에서 없던 값과 누락 값은 0으로 처리한다. 이는 공식 기본 one-hot 대신 품목별 범주 수에 맞춘 수정이며, 논문 기본 설정을 그대로 재현한 실험은 아니다. 수치 변수용 별도 임베딩은 이번 설정에서 사용하지 않는다.

최근 3개월 평균을 s=max(평균,1)로 두고 y/s를 예측한다. 각 출력 p에 대해 s×|y/s−p|=|y−s×p|이므로 원래 수량 단위 절대오차와 동일하다. 여러 출력 각각의 손실을 평균하고, 고정된 학습 정답 평균으로 나누어 경사 크기만 조정한다. 추론에서는 네 출력을 평균하고 s를 곱한 뒤 음수를 0으로 제한한다. 평가 정답은 원래 값을 그대로 사용한다.

CPU 2스레드, BLAS 1스레드, 배치 2,048행, 출력 4개, 블록 2개, 폭 128, dropout 0.1, AdamW 학습률 0.001·weight decay 0.0001, seed 42로 고정한다. 최대 30회 학습하며 검증 WAPE가 5회 연속 개선되지 않으면 중단한다. 각 회차의 모델·옵티마이저·난수 상태를 별도 파일에 보존하고 최저 검증 WAPE 회차를 선택한다. 메모리 여유 1.5GiB 미만 또는 한 단계 2시간 초과 시 감독 프로세스가 자신이 실행한 학습만 중단한다. 이는 발열·전원 문제의 해결이나 안전 보장이 아니며 재부팅 후 자동 재시작하지 않는다. 중단 파일을 덮어쓰는 자동 재개 기능은 제공하지 않는다.

두 검증 기간의 절대오차 합계를 실제 사용량 합계로 나눈 WAPE가 기준보다 낮을 때만 검증상 후보로 선택한다. 선택을 파일에 먼저 기록한 후 10~12월 재사용 평가를 계산한다. 이 기간은 독립 확증이 아니며 회차나 설정 선택에 사용하지 않는다. 개선 여부·BIAS·월별 결과를 함께 확인하고 서비스는 자동 교체하지 않는다. 단일 설정 실패를 TabM 전체의 한계로 단정하지 않는다.

검사: 학습 기간만 이용한 범주·정규화 처리, 원래 단위 손실과의 일치, 시계열 분할, 실제 역전파와 출력 평균 규칙의 네 가지 테스트를 통과했다. 실제 진행은 `outputs/tabm_v2/events.jsonl`과 단계별 로그로 확인한다. 완료 전 성능 개선을 주장하지 않는다.

초기 v1은 2,675,790행의 첫 학습 배치까지 실행했다. Windows 가상환경 실행기가 별도 인터프리터를 띄우는 구조를 확인하여, 안전 중단 시 실행기만 종료하지 않고 그 하위 프로세스까지 종료하도록 보완했다. v1의 본 작업 프로세스 트리를 종료하고 기존 기록은 보존한 채 v2를 시작했다. 데이터·모델·학습 조건을 바꾼 재탐색이 아니라 중단 안전장치 수정이며, v1을 완료 실험으로 집계하지 않는다. 이 안전장치는 컴퓨터 전원·발열 문제를 해결했다는 의미가 아니다.
