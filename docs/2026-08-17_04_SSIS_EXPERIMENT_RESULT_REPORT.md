## 0. 먼저 읽는 결론

이 실험은 다음 달 출고량을 맞히는 데서 끝나지 않는다. 원장의 반품·정정값을 보존하면서 실제
사용량을 분리하고, 다음 달 수요를 예측한 뒤, 예측오차와 비용 가정을 이용해 목표재고와
제안발주량으로 변환하는 전 과정을 검증한다.

현재까지의 결론은 다음과 같다.

1. **수요예측의 잠정 선택모형**은 외부위험을 넣지 않은 `검증 조정 수요전용 LightGBM`이다.
   2025-08~12의 605,438행에서 WAPE 35.714%였고 가장 좋은 단순 기준예측 40.022%보다
   4.307%p, 상대 10.76% 낮았다.[^data-demand-snapshot]
2. **외부위험 모형은 아직 선택하지 않는다.** 수요전용 스냅샷에서는 뉴스·원자재·Module C의
   15개 입력열이 모두 0이었다. 현재 재실행에서는 뉴스 110,256행, 원자재 316,986행, 무역
   20,345행, Module C 316,986행의 점수 생성까지 성공했지만 학습·평가 효과는 아직 확정 전이다.
   앞의 0열 결과와 현재 재실행을 같은 실행처럼 섞지 않는다.[^data-external][^data-external-active]
3. **발주량은 예측값과 같지 않다.** 예측량에 보호기간, 예측오차, 비용비, 현재 재고포지션을
   차례로 적용해야 제안발주량이 된다.
4. **병렬 시험값(shadow value)**은 실제 권고와 분리한다. 뉴스·원자재·무역으로 계산한
   목표재고는 검증용 비교값일 뿐 실제 제안발주량을 바꾸지 않는다.
5. **운영 자동발주는 아직 승인할 수 없다.** 새 독립 평가기간, 실제 발주·입고·미충족·비용자료,
   공식 품목 대응표가 없기 때문이다. 현재 결과는 연구 수준의 비교성과다.

백그라운드 외부위험 전수 재실행이 끝나면 외부모형의 지표만 별도 표에 추가한다. 선택 원칙은
`예측오차만 최소화`가 아니라 `예측오차·과소예측 편향·품절·평균재고를 함께 개선`하는 모형을
고르는 것이다.

## 1. 용어와 공식을 먼저 이해하기

### 1.1 통일 용어

| 이 보고서의 용어 | 코드·영문 표현 | 쉬운 뜻 |
|---|---|---|
| 실제 관측수요 | actual, `y` | 평가기간에 실제로 발생한 양수 정상출고량 |
| 예측수요 | forecast/prediction, `ŷ` | 과거자료로 추정한 다음 달 사용량 |
| 단순 기준예측 | naive/simple baseline | 지난달 값, 최근 3개월 평균처럼 학습 없이 만든 비교기준 |
| 조정 전 기준모형 | baseline LightGBM | 설정값 탐색 전 LightGBM |
| 검증 조정모형 | tuned LightGBM | 과거→미래 순서의 검증자료에서 설정값을 조정한 LightGBM |
| 수요패턴 선택기 | pattern router | ADI·CV² 수요유형별로 성능이 나은 예측기를 고르는 규칙 |
| 재사용 평가구간 | reused evaluation slice | 이전 실험에서 이미 확인해 최종 미사용 시험으로 볼 수 없는 기간 |
| 병렬 시험값 | shadow value | 실제 권고에는 반영하지 않고 옆에서 효과만 비교하는 계산값 |
| 자동 권고 차단 규칙 | safety/quality gate | 데이터·매핑·검증 조건이 부족할 때 자동 권고를 막는 규칙 |
| 재고정책 검증 실험 | inventory-policy simulation | 과거 실제수요로 품절과 평균재고를 비교하는 실험 |
| 목표재고 | order-up-to level, `S` | 다음 검토·입고까지 버티도록 맞추려는 재고수준 |
| 재고포지션 | inventory position, `IP` | 현재고 + 발주잔량 - 미충족 주문량 |
| 제안발주량 | recommended order, `Q` | 목표재고에서 재고포지션을 뺀 뒤 0보다 작지 않게 한 값 |

`baseline`은 문헌과 코드에서 여러 의미로 쓰인다. 이 보고서에서는 단순 산술예측은 `단순
기준예측`, LightGBM 비교대상은 `조정 전 기준모형`이라고 구분한다. `논문`은 저자와 연도가
표시된 참고문헌만 뜻하며, `WAPE`, `LightGBM`, `Noisy-OR`는 논문명이 아니라 지표·알고리즘·
결합방식의 이름이다.

### 1.2 예측오차 공식: WAPE

```text
WAPE (Weighted Absolute Percentage Error, 가중절대백분율오차)
     = Σ |actual demand - forecast demand| / Σ |actual demand| × 100
     = Σ |y - ŷ| / Σ |y| × 100
```

- `actual demand / y`: 실제 관측수요
- `forecast demand / ŷ`: 예측수요
- `absolute error / |y-ŷ|`: 방향을 없앤 예측오차의 크기
- `Σ`: 평가대상 전체를 합한다는 뜻

WAPE는 **낮을수록 좋고 이론적 최솟값은 0%**다. 그러나 의료재고에 공통으로 적용되는
`20% 이하면 우수`, `30% 이하면 최적` 같은 보편 기준은 없다. 수요의 간헐성, 품목 수,
평가기간과 0수요 비율이 다르면 같은 백분율의 난이도가 달라지기 때문이다. 본 실험에서는
절대 숫자 하나로 합격을 정하지 않고 다음을 함께 본다.

1. 같은 행·같은 기간에서 단순 기준예측과 조정 전 기준모형보다 낮은가?
2. 기간·기관·수요패턴별로 나눠도 개선 방향이 유지되는가?
3. WAPE 개선이 품절 감소로 이어지며 평균재고를 과도하게 늘리지 않는가?

WAPE가 40.022%에서 35.714%로 바뀌었다면 **4.307%포인트 감소**, 기존 오차 대비로는
`(40.022-35.714)/40.022=10.76% 감소`라고 구분해 표현한다.

### 1.3 과소·과다예측 공식: BIAS

```text
BIAS% (예측편향률) = Σ(forecast demand - actual demand) / Σ actual demand × 100
                    = Σ(ŷ - y) / Σy × 100
```

0%에 가까울수록 전체 치우침이 적다. 음수면 실제보다 적게 예측해 품절 위험을 키울 수 있고,
양수면 과다예측해 과잉재고·폐기 위험을 키울 수 있다. WAPE와 반드시 같이 본다.

### 1.4 수요패턴 공식: ADI와 CV²

```text
ADI (Average Demand Interval, 평균 수요발생 간격) = T / n+
CV² (Squared Coefficient of Variation, 변동계수 제곱) = (s+ / μ+)²
```

- `T`: 전체 관측월 수, `n+`: 수요가 0보다 큰 월 수
- `μ+`: 양수 수요량의 평균, `s+`: 양수 수요량의 표준편차

ADI가 크면 수요가 드물고, CV²가 크면 발생량 변화가 크다. 두 값으로 안정형(smooth),
간헐형(intermittent), 변동형(erratic), 불규칙 대량형(lumpy)을 구분한다.[^ref-syntetos]

### 1.5 발주 공식의 전체 모습

```text
protection period / 보호기간       H  = review period R + lead time L
protection demand / 보호기간 수요  D_H = monthly forecast ŷmonth × H / 30
critical ratio / 임계비율          p* = underage cost Cu / (Cu + overage cost Co)
safety factor / 안전계수           z* = Φ⁻¹(p*)
safety stock / 안전재고            SS = z* × monthly error σmonth × √(H/30)
target stock / 목표재고            S  = D_H + SS
inventory position / 재고포지션    IP = on-hand + on-order - backorder
recommended order / 제안발주량     Q  = max(S - IP, 0)
```

다음 달 예측량만큼 주문하는 식이 아니다. 검토주기와 입고대기기간의 수요를 계산하고,
틀릴 가능성에 대비한 안전재고를 더한 뒤, 이미 보유하거나 주문한 재고를 차감한다는 뜻이다.

### 2.2 `음수만 기록된 달`은 무엇인가

정상출고량에는 반품이나 과거 입력 정정이 역방향 거래로 기록된 음수가 존재할 수 있다.

```text
signed ledger outbound / 부호 보존 원장출고 = Σ normal_outbound
positive model demand / 양수 모델수요       = Σ max(normal_outbound, 0)
negative count / 음수 건수                  = count(normal_outbound < 0)
negative amount / 음수 절댓값               = Σ |min(normal_outbound, 0)|
```

`음수만 기록된 달(negative-only month)`은 해당 기관·부서·품목의 한 달 정상출고에 양수 사용은
없고 반품·정정으로 보이는 음수만 있었다는 뜻이다. 행을 삭제하지 않는다. 원장 대사용 부호
합계와 음수 건수·양은 보존하되, 사람의 실제 사용량을 `-89개`로 학습할 수 없으므로 모델
수요만 0으로 둔다.

실제 월별 자료 발췌 사례다. 기관·품목 식별자는 SHA-256 앞 8자리로 가명화했다.[^data-negative]

| 사례 | 월 | 기관 표본ID | 품목 표본ID | 부호 보존 합계 | 모델 수요 | 음수 건수·절댓값 | 해석 |
|---|---:|---|---|---:|---:|---:|---|
| 음수만 기록 | 2025-07 | H-cfb951b0 | H-188aa8e2 | -89 | 0 | 1건·89 | 사용량 -89가 아니라 반품·정정 89로 보존 |
| 양수·음수 혼재 | 2024-05 | H-8263f413 | H-8a2081f4 | 18 | 19 | 1건·1 | 양수 사용 19와 음수 조정 1이 함께 존재 |
| 양수·음수 상계 | 2024-06 | H-b4e0dfa4 | H-f7c34b9a | 0 | 4 | 1건·4 | 원장 합은 0이지만 양수 출고 4는 학습에 유지 |

현재기간에는 음수가 포함된 월 15개 중 음수만 기록된 달 1개와 양수·음수가 함께 있던 달
14개가 있었다. 이 규칙은 논문 공식이 아니라 원장값과 학습값을 혼동하지 않기 위한
**데이터 계약**이다.

### 2.3 과거자료에서 연결되지 않아 제외한 품목

2018~2019 로컬 품목 175,760개 가운데 146,757개(83.50%)는 현재 대표품목과 엄격하게
연결됐다. 나머지 29,003개는 과거 이름으로 임시 표준키를 만들 수 있었지만 현재 대표품목과
동일하다고 확정할 증거가 부족했다. 해당 143,736개 월별 행, 양수 모델수요 합계
12,402,768.2116은 과거 학습에서 제외했다.[^data-mapping]

| 과거 품목 표본ID | 원문 품목명 | 연결방법 | 신뢰도 | 학습 여부 | 제외 이유 |
|---|---|---|---:|---|---|
| H-4c26d731 | `#6878 314 012 bur` | 과거 이름 임시연결 | 0.50 | 제외 | 현재 대표품목과 엄격 일치하지 않음 |
| H-b218d7e4 | `#858 314 010 bur` | 과거 이름 임시연결 | 0.50 | 제외 | 비슷한 이름만으로 동일품목을 확정할 수 없음 |
| H-f9987eed | `#8878 314 012 bur` | 과거 이름 임시연결 | 0.50 | 제외 | 규격 차이를 무시하면 다른 품목을 합칠 위험 |

`제외`는 원천행 삭제가 아니다. 감사와 재매핑을 위해 행과 임시 표준키는 보존하고, 현재 품목의
미래수요를 학습시키는 표본으로만 쓰지 않는다. 공식 대응표가 들어오면 다시 연결할 수 있다.

### 2.4 외부위험 데이터가 연결되지 않은 사례

고정해 둔 수요전용 스냅샷의 특성표에는 뉴스 4개, 원자재 3개, Module C 8개로 총 15개
외부위험 열이 있으나 학습·검증·평가 구간의 0이 아닌 관측이 모두 0개였다.[^data-external]

- 수요·달력·재고이력만 쓰는 모형 A는 학습·평가한다.
- 값이 전부 0인 뉴스·원자재·Module C 모형은 성능 비교에서 제외한다.
- 0을 `위험 없음`으로 해석하지 않고 입력파일 미연결 상태로 기록한다.
- 과거 별도 외부신호 결과는 `과거 실행 참고값`으로 구분한다.

이 문제를 확인한 뒤 같은 대용량 로컬 원천 범위에서 외부점수를 먼저 생성하는 재실행을 시작했다.
뉴스·원자재·무역·Module C 점수파일은 생성됐고, 특성생성 이후의 비영률과 모형효과는 실행이
끝난 뒤 별도 결과표에 채운다. 점수행이 생겼다는 사실만으로 예측력이 입증된 것은 아니다.
연결·제외 실제 사례는 별도 부록에 정리했다.[^data-external-active]

현재 로컬 품목이 표준품목에 연결되지 않아도 자체 수요이력은 존재한다. 그런 품목은 기관·부서·
로컬 품목 단위 수요예측에는 유지하고 품목 간 통합학습·외부위험 전파만 차단한다.

## 4. 예측모형은 어떻게 구성했는가

### 4.1 단순 기준예측 6개

복잡한 모형의 추가가치를 확인하기 위해 지난달 수요, 최근 3개월 평균·중앙값, 최근 6개월
평균, 전년도 같은 달 수요, 지금까지의 누적평균을 먼저 계산한다. 이를 `단순 기준예측`이라
부르고 LightGBM의 `조정 전 기준모형`과 구분한다.

### 4.2 LightGBM 입력정보

수요전용 LightGBM은 총 51개 후보 특성을 다음 범주로 사용한다.[^code-model]

- **시계열 이력**: 1·2·3·6·12개월 전 수요, 최근 3·6·12개월 평균·표준편차, 중앙값, 누적평균
- **간헐성**: 최근 6·12개월 0수요 비율, 관측월 수, 연속구간 이력 길이
- **재고·입출고 과거값**: 입고, 기말재고, 품절률, 폐기량의 1~3개월 전 값
- **달력**: 연·월·분기, 겨울·여름, 전년동월 값과 증감률
- **품목·기관 범주**: 익명 기관·부서, 승인 표준품목 그룹·family·하위유형·규격·단위
- **원장 품질**: 부호 보존 출고, 양수 모델수요, 음수 거래 건수·절댓값

평가할 달의 기말재고나 실제수요처럼 아직 알 수 없는 값은 입력에서 제외한다. 숫자 결측은
학습구간 중앙값으로 채우고 범주 목록도 학습구간에서만 만들어 미래정보 누출을 막는다.

### 4.3 조정 전 기준모형과 검증 조정모형

두 모형은 입력행·특성과 손실함수(`regression_l1`, 절대오차 최소화)가 같고 설정만 다르다.

| 설정 | 조정 전 기준모형 | 검증 조정모형 | 쉬운 설명 |
|---|---:|---:|---|
| 트리 수 `n_estimators` | 160 | 1,999 | 순차적으로 만드는 의사결정나무 수 |
| 학습률 `learning_rate` | 0.05 | 0.02723 | 나무 한 개의 수정폭 |
| 잎 수 `num_leaves` | 31 | 249 | 한 나무가 표현하는 세부 구간 |
| 최소 잎 표본 | 100 | 126 | 너무 작은 집단 분할을 막는 기준 |
| 행 표본비율 | 0.90 | 0.7331 | 각 반복에서 쓸 학습행 비율 |
| 열 표본비율 | 0.90 | 0.6134 | 각 나무에서 쓸 특성 비율 |
| L2 규제 | 0.10 | 0.07198 | 큰 모형값을 완화하는 규제 |
| L1 규제 | 0 | 0.02041 | 불필요한 복잡도를 줄이는 규제 |

검증 조정값은 2024년 3·4분기와 2025년 1·2분기의 네 시간순 검증구간을 합친 WAPE를
최소화하도록 60회 탐색했다. 시험기간은 설정 선택에 사용하지 않았다.[^data-tuning] 트리 수가
약 12배여서 학습시간은 16.4초에서 166.1초로 약 10.13배 증가했다.

### 4.4 수요패턴 선택기

수요패턴 선택기는 새 알고리즘이 아니라 `안정형에는 예측기 A, 간헐형에는 예측기 B`처럼
검증성과에 따라 후보를 고르는 규칙이다. 전체 WAPE가 가장 낮은 단일 모형을 자동 대체하지
않으며, 같은 평가행에서 WAPE·BIAS·재고성과가 더 나을 때만 최종 후보가 된다.

## 5. 예측에서 제안발주량까지

### 5.1 주기검토 목표재고 방식

재고를 `R`일마다 검토하고 입고까지 `L`일이 걸리면 `H=R+L` 동안 필요한 재고를 준비한다.

```text
H = R + L                         보호기간
D_H = ŷmonth × H/30               보호기간 예상수요
p* = Cu/(Cu+Co), z* = Φ⁻¹(p*)    비용비에 따른 안전계수
SS = z* × σmonth × √(H/30)       안전재고
S = D_H + SS                      목표재고
IP = on_hand + on_order - backorder  재고포지션
Q = max(S-IP, 0)                  제안발주량
```

`Cu(underage cost, 과소재고비)`는 부족 손실, `Co(overage cost, 과다재고비)`는 잔여 손실이다.
현재 `Co:Cu=1:9`는 실제 비용이 아니라 실험 가정이다. 따라서 **비용비가 주어졌을 때의
조건부 최적식**이며 기관별 실제 경제적 최적발주량이라고 단정하지 않는다.[^ref-newsvendor]

### 5.2 실제 계산 예시

월 예측수요 3.5175, 검토주기 30일, 입고대기 15일, 재고포지션 0인 사례다.

```text
보호기간                    H   = 30 + 15 = 45일
보호기간 예상수요            D_H = 3.5175 × 45/30 = 5.2763
예측오차 기반 안전재고        SS  = 1.0552
기본 목표재고                S   = 6.3315
기본 제안발주량               Q   = max(6.3315 - 0, 0) = 6.3315
외부위험 병렬 시험 목표재고        = 6.4011
외부위험 병렬 시험 증가분          = 0.0696
외부위험의 실제 권고 반영 여부     = 아니오
```

포장단위와 최소주문량을 받으면 마지막 단계에서 주문 가능한 단위로 올림한다. 현재 원천에는
발주잔량과 미충족 주문량이 충분하지 않아 실제 재고포지션과 다를 수 있다.

## 6. 외부위험 병렬 실험

### 6.1 `병렬 시험값`의 의미

병렬 시험값은 `위험신호를 반영했다면 목표재고가 얼마나 달라졌을까`를 보여주는 비교값이다.
코드 열 이름에는 호환성을 위해 `shadow_*`가 남아 있지만 본문에서는 `병렬 시험값`이라 부른다.

```text
실제 목표재고 = 기본 목표재고
실제 제안발주량 = 기본 제안발주량
병렬 시험 목표재고 = 외부위험을 가정해 다시 계산한 목표재고
운영 반영 여부 = false
차단 사유 = 독립 평가기간의 실증 미통과
```

### 6.2 뉴스기사 점수

```text
article score / 기사점수 = exp(Σ αk × log(wk)),  Σαk = 1
monthly risk / 월 위험점수 = 1 - exp(-Σ article score / p90 scale)
```

`wk`는 출처신뢰도·사건심각도·관련성 항목점수, `αk`는 항목별 영향력, `p90 scale`은 같은
위험군에서 상위 10% 경계로 만든 상대척도다. 기사점수는 확률이 아니다.[^ref-news]

### 6.3 원자재 변동성과 Noisy-OR

```text
일별자료: 30일 변동성 = 30일 수익률 표준편차 × √30
주별자료: 30일 변동성 = 주별 수익률 표준편차 × √(30/7)
월별자료: 30일 변동성 = 월별 수익률 표준편차

군집별 위험 rc = 같은 원인의 경로위험 중 최댓값
복합위험 = 1 - ∏c(1 - rc)
```

`Noisy-OR`는 여러 위험 중 하나라도 발생하면 전체 위험을 높이는 결합방식이다. 같은 충격을
뉴스·가격·무역에서 반복 측정했을 수 있으므로 같은 원인끼리 묶어 최댓값만 남기고 서로 다른
원인군 사이에서만 결합한다.

### 6.4 현재 실증 결과와 선택

과거 별도 실행에서 외부위험의 최대 WAPE 개선은 0.087%p였다. PP 수입가→2개월 뒤 기말재고의
최신 24개월 p값은 0.4617이었고, 90개 경로는 다중검정 보정 후 유의한 경로가 0개였다.
MFDS 공급중단 1,936건 중 마스터 매칭은 839건이었으나 영향 사용량 비중은 1.62%였다.

수요전용 스냅샷의 외부열은 모두 0이어서 관련 모형을 선택할 수 없었다. 현재 재실행은
뉴스·원자재·무역·Module C 점수 생성까지 성공했지만 Module C 품질판정은 PASS 0,
REVIEW 4,647, BLOCKED 322였다. 특성생성·학습·평가가 끝나더라도 새 독립기간의 신호별
제거실험(ablation)을 통과하기 전에는 병렬 시험값으로만 제공한다.[^data-external-active]

## 7. 재고정책 검증 실험과 자동 권고 차단 규칙

### 7.1 이 장에서 만드는 것

별도의 `재고정책 시뮬레이터` 제품을 설명하는 장이 아니다. 과거 실제수요를 월별로 다시
흘려보내며 모델 정책과 단순 정책을 같은 초기조건에서 비교하는 **검증 실험**이다. WAPE뿐
아니라 충족률(fill rate), 품절월 비율, 평균재고와 회전율을 본다.

### 7.2 기존 동일조건 비교결과

2025-09~12, 77,575개 시계열의 기존 결과다.

- 모델 정책: 충족률 96.12%, 품절월 7.92%, 평균재고 171.40, 회전율 4.43, WAPE 33.51%
- 단순 정책: 충족률 95.31%, 품절월 11.30%, 평균재고 197.39, 회전율 3.85, WAPE 40.28%
- 차이: 충족률 +0.81%p, 품절월 -3.38%p, 평균재고 -13.17%, 회전율 +0.58

방향성은 유리하지만 평가구간 실제값으로 변동성을 추정했고 첫 목표재고를 초기재고로 사용해
절대성과가 낙관적일 수 있다. 새 독립기간에서 재검증한다.

### 7.3 자동 권고 차단 규칙

`안전 gate` 대신 `자동 권고 차단 규칙`이라 부른다. 이는 성능지표가 아니라 근거가 부족한 행이
발주권고로 넘어가는 것을 막는 안전장치다.

```text
장기 무수요·미운영                   → 제안발주량 0
자료누락·오래된 관측                 → 자동값 없음, 사람 검토
품목·원자재 연결 충돌                → 외부위험 반영 차단
병렬 시험의 독립검증 미통과          → 기본 제안발주량 유지
승인 동등품 재고 존재                → 긴급부족 표시 억제
```

정책 v1.1에서 비양수 재고 후보 10,910개가 긴급부족 후보 17개로 줄었다. 99.84% 감소는
`정확도 99.84%`가 아니라 차단조건 통과 수의 감소다. 최신 v1.2 결과로 다시 확정한다.

| Tweedie LightGBM | 37.272% | 50.741 | 188.642 | -1.971% | 큰 오차·편향 완화 후보, WAPE 열세 |

2025-10~12의 359,335행만 보면 수요전용 LightGBM WAPE는 35.703%, 패턴별 혼합 선택기는
35.801%였다. 혼합 선택기는 WAPE가 0.098%p 나빠졌지만 RMSE는 208.583에서 201.186으로,
BIAS%는 -7.592%에서 -5.890%로 개선됐다.[^data-ensemble]

따라서 WAPE를 1순위로 둘 때 주모형은 단일 수요전용 LightGBM이다. 혼합 선택기는 큰 오차와
과소예측을 줄일 가능성이 있으므로 **재고정책용 도전모형**으로 남긴다. 둘 다 이미 확인한
2025년 평가기간 결과이므로 `최종 일반화 성능`으로 표현하지 않는다.

### 8.2 고정 WAPE 합격선을 두지 않는 이유

본 데이터는 월별 0수요 행이 39.65%이고 시계열 중앙 관측월이 6개월인 간헐·단기 자료다.
따라서 다음 내부 판정규칙을 사용한다.

- **예측 통과**: 같은 행에서 기준모형보다 WAPE가 낮고 기간·패턴별 악화가 제한적이며 BIAS 개선
- **재고정책 통과**: 충족률 또는 품절이 개선되고 평균재고 증가가 합의된 범위 안에 있음
- **통계 확인**: 월 또는 시계열 블록 부트스트랩으로 WAPE 차이의 신뢰구간 확인
- **운영 통과**: 새 독립기간, 공식 대응표, 주문·입고·비용자료와 담당자 승인 충족

평균재고 허용 증가율과 목표 충족률은 정보원 업무기준·실제 비용자료가 있어야 확정할 수 있다.
연구진이 임의로 `WAPE 30%` 같은 합격선을 만들지 않는다.

## 9. 문제와 개선 우선순위

### 9.1 확인된 문제

1. 2025년 하반기를 이미 여러 번 확인해 최종 독립 시험기간이 없다.
2. 과거 로컬 품목 29,003개를 현재 대표품목에 엄격 연결하지 못했다.
3. 수요전용 스냅샷의 외부위험 15개 입력열이 모두 0이었고, 현재 재실행은 학습·평가 중이다.
4. 잠정 선택모형도 전체 백테스트 BIAS% -9.617%의 과소예측 편향이 남는다.
5. 발주잔량·부분입고·미충족 자료가 없어 실제 재고포지션을 완전히 재현하지 못한다.
6. `Co:Cu=1:9`가 실제 보유·폐기·긴급구매 비용에서 추정된 값이 아니다.
7. 중앙 관측월 6개월이라 개별 품목의 평균·분산이 불안정하다.
8. 긴급부족, 품목–원자재 연결, 뉴스영향의 사람 검증 정답이 부족하다.

### 9.2 개선 우선순위

1. 외부위험 전수 재실행 완료 후 외부모형 지표·행 수·commit을 별도 실행으로 고정한다.
2. 수요전용 LightGBM과 패턴별 혼합 선택기를 동일 실제 초기재고에서 비교한다.
3. 블록 부트스트랩으로 WAPE·BIAS·재고성과 차이의 불확실성을 제시한다.
4. 비용비, 리드타임과 안전재고 상한을 격자로 바꿔 민감도 곡선을 만든다.
5. 미연결·미매핑 품목 검토목록을 사용량·오류영향 순으로 제공한다.
6. 외부위험 파일의 생성시각·행 수·기간·비영 비율을 실행 전 필수검사로 둔다.
7. 공식 대응표와 주문·입고·미충족·비용자료로 경제적 발주식을 다시 추정한다.
8. 이후 처음 들어오는 새 기간을 잠근 뒤 최종 독립시험으로 한 번만 평가한다.

## 12. 최종 결론

본 실험은 `원천자료 → 모델 학습값 → 수요예측 → 안전재고 → 목표재고 → 제안발주량`의 연결을
추적 가능한 흐름으로 만들었다. 음수 출고를 삭제하거나 음의 수요로 학습하지 않고 원장값과
모델값을 분리했으며, 엄격히 연결되지 않은 과거품목을 감사용으로 보존하면서 학습에서 격리했다.

현재 잠정 선택은 **외부위험을 사용하지 않은 검증 조정 수요전용 LightGBM**이다. 동일한
605,438행에서 가장 좋은 단순 기준예측보다 WAPE가 4.307%p 낮고, 시간순 혼합 선택기보다도
0.012%p 낮았기 때문이다. 그러나 BIAS% -9.617%의 과소예측 편향과 독립 시험기간 문제가 남아
`최적모형 확정`이 아니라 `현재 증거에서 WAPE가 가장 낮은 연구모형`으로 표현한다. 패턴별
혼합 선택기는 RMSE와 BIAS가 더 좋아 재고성과를 확인할 도전모형으로 남긴다.

외부위험은 수요전용 스냅샷에서는 입력이 연결되지 않았고, 현재 재실행에서는 점수 생성까지
복구됐지만 품질 PASS와 예측효과가 확정되지 않았다. 따라서 관련 계산은 **실제 권고와 분리된
병렬 시험값**으로만 제공한다. 자동 권고 차단 규칙은 오래된 재고, 누락, 승인되지 않은 매핑과
검증 미통과가 발주권고로 넘어가지 않게 한다.

다음 단계는 공식을 계속 추가하는 일이 아니다. 외부위험 재실행을 수요전용 스냅샷과 분리해
고정하고 동일조건 재고실험과 불확실성 분석을 끝낸 뒤, 공식 매핑·주문·입고·비용자료와 새
평가기간이 확보될 때 운영 가능성을 다시 판정하는 것이다.
