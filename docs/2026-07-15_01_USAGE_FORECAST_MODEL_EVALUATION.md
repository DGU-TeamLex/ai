# raw_stock 사용량 예측 모델 평가

작성일: 2026-07-15  
데이터 기준: `raw_stock/*.DAT`  
예측 단위: `기관 + 부서 + 내부 물품코드`의 다음 달 정상출고량

## 1. 결론

품목 표준화가 완료되지 않았어도 **기관별 로컬 사용량 예측은 가능**하다. 현재 원본에서
예측 키 416,128개가 만들어졌고, 같은 키의 월별 품목명 변경은 0건이며 사용량 결측도
0건이다.

다만 표준화되지 않은 품목을 다른 기관의 동일 제품과 합치거나 뉴스·원자재 위험에 연결하면
안 된다. 이 기능에는 승인된 `canonical_item_id` 또는 `item_family_id`가 별도로 필요하다.

현재 운영 기본 모델은 교차검증 WAPE가 가장 낮은 **LightGBM L1**이다. 독립 테스트에서는
LightGBM Tweedie가 더 좋았으므로 challenger 모델로 함께 저장한다. 테스트를 보고 기본
모델을 바꾸면 평가 누수가 되므로, 다음 월 데이터에서도 Tweedie 우위가 반복되는지 확인한
뒤 전환한다.

## 2. 데이터 학습 가능성

| 항목 | 결과 | 판단 |
|---|---:|---|
| 원본 기간 | 2024-01~2025-12 | 24개월 |
| 월별 재고·사용량 행 | 3,729,983 | 학습 가능 |
| 로컬 시계열 | 416,128 | 전역 모델 필요 |
| 학습·평가 라벨 | 2,693,219 | 충분 |
| 사용량 결측 | 0 | 문제 없음 |
| 음수 사용량 | 1건, -89 | 라벨에서 제외 |
| 0 사용량 | 1,215,269건, 32.58% | 간헐수요 고려 필요 |
| 월별 품목명 변경 시계열 | 0 | 로컬 키 안정 |
| 6개월 이상 관측 시계열 | 219,634, 52.78% | 절반은 짧은 이력 |
| 12개월 이상 관측 시계열 | 134,054, 32.21% | 계절성 학습 제한 |
| 관측 구간 길이 중앙값 | 1개월 | 월 공백 처리 필수 |

개별 시계열은 최대 24개월이고 절반가량은 6개월 이하이므로 품목마다 별도 모델을 학습하지
않는다. 기관·부서·품목 전체에서 공통 패턴을 학습하는 전역 LightGBM을 사용한다.

정규화 상태가 `unresolved`인 데이터는 전체 월별 행의 28.45%지만 사용량의 5.74%다. 이
데이터도 로컬 키 예측에는 포함하되 기관 간 통합, 질병 매핑 및 원자재 매핑에서는 제외한다.

## 3. 수정한 문제

### 월 공백을 과거 lag로 사용하던 문제

기존 코드는 이전 행을 이전 달로 간주했다. 예를 들어 1월 다음 관측이 4월이면 1월 값을
4월의 직전 월 값처럼 사용할 수 있었다. 수정 후 월이 연속되지 않으면 새 구간으로 분리하고
lag, rolling, target을 초기화한다.

### 테스트 전체 평균을 사용하는 기준선 누수

기존 단순평균 기준선은 평가할 전체 DataFrame의 시계열 평균을 사용했다. 뒤쪽 테스트 달의
관측값이 앞쪽 예측에 반영될 수 있어 제거했다. 모든 기준선은 각 예측 시점까지 계산된
feature만 사용한다.

### 실제 미래 예측이 없던 문제

기존 `stock_predictions.csv`는 실제값이 있는 과거 테스트 행만 포함했다. 수정 후 파일을
다음처럼 분리한다.

- `outputs/stock_backtest_predictions.csv`: 실제값이 있는 테스트 예측
- `outputs/stock_predictions.csv`: 마지막 원본 월 다음 달의 실제 미래 예측

현재 원본의 마지막 달은 2025-12이므로 미래 산출물은 2026-01 예측이다. 현재 시점 기준
7개월 지난 데이터이므로 모든 행에 `is_stale_data=true`가 기록된다. 현재 운영 예측으로
사용하려면 2026년 원본을 먼저 추가해야 한다.

## 4. 평가 설계

모든 방법은 다음 달 사용량을 예측한다.

| 구간 | 용도 |
|---|---|
| 2024-01~2024-12 origin | 1차 fold 학습 |
| 2025-01~2025-03 origin | 1차 fold 검증 |
| 2024-01~2025-03 origin | 2차 fold 학습 |
| 2025-04~2025-06 origin | 2차 fold 검증 |
| 2024-01~2025-06 origin | 최종 재학습 |
| 2025-07~2025-11 origin | 독립 테스트 |

비교 방법:

- 직전 달 사용량
- 최근 3개월 평균
- 최근 3개월 중앙값
- 최근 6개월 평균
- 전년 동월
- 현재 연속 구간 누적 평균
- LightGBM L1
- LightGBM Tweedie

MAPE는 0 또는 소량 사용량에서 과도하게 커지므로 모델 선택에는 WAPE를 사용한다. MAE,
RMSE, RMSLE, 총량 편향도 함께 확인한다.

## 5. 교차검증 결과

| 방법 | WAPE | MAE | RMSE | 총량 편향 |
|---|---:|---:|---:|---:|
| LightGBM L1 | **40.19%** | **54.22** | 294.38 | -7.43% |
| LightGBM Tweedie | 40.77% | 55.01 | **212.01** | +4.02% |
| 최근 3개월 평균 | 44.52% | 60.06 | 234.07 | +5.79% |
| 최근 3개월 중앙값 | 45.11% | 60.87 | 243.26 | +2.73% |
| 최근 6개월 평균 | 45.30% | 61.12 | 233.27 | +5.71% |
| 누적 평균 | 45.94% | 61.98 | 234.40 | +4.46% |
| 직전 달 | 48.07% | 64.86 | 255.18 | +3.89% |
| 전년 동월 | 54.92% | 74.10 | 269.47 | +5.44% |

L1은 두 fold 모두 WAPE가 가장 낮았다. 최근 3개월 평균보다 WAPE가 4.33%p 낮아 현재
기본 모델로 선택했다. Tweedie는 WAPE가 0.58%p 높지만 RMSE와 총량 편향이 더 안정적이다.

## 6. 독립 테스트 결과

| 방법 | WAPE | MAE | RMSE | 총량 편향 |
|---|---:|---:|---:|---:|
| LightGBM Tweedie | **37.60%** | **51.18** | **189.58** | -4.51% |
| LightGBM L1 | 38.87% | 52.92 | 292.29 | -15.66% |
| 최근 3개월 평균 | 40.02% | 54.48 | 201.31 | -6.04% |
| 최근 3개월 중앙값 | 41.16% | 56.03 | 211.69 | -8.51% |
| 최근 6개월 평균 | 41.25% | 56.15 | 205.26 | -6.23% |
| 누적 평균 | 44.41% | 60.46 | 217.14 | -1.77% |
| 직전 달 | 44.75% | 60.93 | 224.35 | -3.66% |
| 전년 동월 | 52.67% | 71.71 | 257.33 | +2.99% |

테스트에서는 Tweedie가 가장 좋았다. 특히 L1은 전체 사용량을 15.66% 과소예측해 재고
업무에서 주의가 필요하다. 현재는 평가 원칙에 따라 L1을 유지하지만 다음 조건 중 하나가
충족되면 Tweedie 전환을 검토한다.

1. 새 월을 추가한 rolling backtest에서 Tweedie가 2회 연속 우위
2. 과소예측 비용이 과대예측 비용보다 크다는 업무 정책 확정
3. WAPE 1%p 이내 후보에서 RMSE·편향을 우선한다는 모델 선택 규칙 승인

## 7. 수요 유형별 해석

독립 테스트에서 smooth 수요는 Tweedie WAPE 33.22%, erratic 수요는 L1 50.38%,
intermittent 수요는 L1 43.06%가 가장 낮았다. 신규·짧은 이력·lumpy 수요는 여전히
46~55% 수준이어서 모델 예측만으로 자동 발주하면 안 된다.

수요 유형별 모델 라우팅은 테스트 결과를 보고 바로 적용하지 않는다. 다음 rolling
backtest에서 같은 유형별 우위가 재현되면 별도 검증 규칙으로 도입한다.

## 8. 실행 방법

```bash
conda activate teamlex
python -m src.preprocessing
python -m src.feature_engineering
python -m src.modeling.training
python -m src.modeling.prediction
```

재실행 시 `src.preprocessing`은 1,600만 원본 행을 다시 읽는다. `raw_stock`이 바뀌지
않았다면 기존 `data/processed/stock_monthly.parquet`을 재사용하고 feature 단계부터 실행할
수 있다.

## 9. 남은 제한

- 원본이 2025-12에서 끝나 현재 운영 시점과 7개월 차이가 난다.
- 최신 월이 추가되기 전에는 2026년 현재 발주량으로 사용하면 안 된다.
- 뉴스·원자재 feature가 전부 0이라 Model B/C는 평가에서 자동 제외됐다.
- 표준화 완료 전에는 기관 간 동일 제품 통합 학습과 질병·원자재 위험 조인이 불가능하다.
- WAPE 37~40%는 기준선보다 낫지만 자동 발주를 단독 승인할 수준으로 간주하지 않는다.
- 품절로 실제 사용량이 억제된 경우 정상출고량만으로 잠재수요를 복원할 수 없다.
