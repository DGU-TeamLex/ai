## 4. 안전상 의도적으로 다르게 구현한 부분

### 4.1 대체 재고 범위

PDF는 `기관 × 품목군` 합계가 양수이면 개별 결품 경보를 제거한다. 그러나
`22G`와 `24G`, `3mL`와 `10mL`처럼 같은 대품목군이어도 임상·운영상 서로 대체할 수
없는 규격이 있다.

따라서 자동 경보 억제는 승인된 다음 네 속성이 모두 같은 경우에만 수행한다.

```text
기관
+ item_family_id
+ item_subtype_id
+ normalized_specification
+ unit_code
```

대품목군 합계는 `broad_family_total_stock`으로 병기하지만 화면 참고용이며 자동
억제에는 쓰지 않는다. 미승인 분류는 대체 가능성을 추정하지 않고 검토 대상으로 보낸다.

### 4.2 원장 정합성 식

PDF 식은 다음과 같다.

```text
정상출고량 > 이전최종재고량 + 구매입고량
```

이 식은 `ledger_document_rule_violation_count`에 원문 그대로 보존한다. 다만
불출입고와 반납입고가 실제 가용재고를 늘릴 수 있으므로 자동 `DATA_MISSING` 판정은
다음 물리 가용량 식을 사용한다.

```text
max(정상출고량, 0)
> max(이전최종재고량, 0)
  + max(구매입고량, 0)
  + max(불출입고량, 0)
  + max(반납입고량, 0)
```

이 차이로 정상 이관입고가 있는 행을 데이터 누락으로 오판하는 것을 막는다.

### 4.3 키와 예측 방식

- 표준명만을 로컬 시계열 키로 쓰지 않는다. 이름 충돌·변경을 막기 위해
  `기관+부서+물품코드`를 원장 시계열 키로 유지하고, 승인 표준 분류를 별도로 결합한다.
- PDF의 재고정책은 결정론적 계산으로 구현했다. 사용량 예측 모델까지 규칙식으로
  대체하지 않았으며, ML·baseline 예측과 정책 계산을 구분한다.
- 현재 검증에서 선택된 champion은 저장소의 시계열 분할 결과를 따른다. PDF의
  LightGBM WAPE 37.6%와 roll3 42.6%는 같은 데이터·분할로 재현되기 전까지 이
  저장소 성능으로 간주하지 않는다.

## 5. 구현된 처리 흐름

```text
raw_stock 행
  -> 원본 거래량 월별 집계
  -> 문서식 위반 / 물리식 위반 / 이전재고 결측 집계
  -> 비음수 정상출고 합·제곱합 보존
  -> 품목별 T, μ, σ, 최근 3개월 수요 계산
  -> NOT_OPERATED / DATA_MISSING / TRUE_STOCKOUT 분류
  -> 승인된 동일 규격 대체군 재고 합산
  -> 비예측품·미운영·대체재고 보유 필터
  -> URGENT_SHORTAGE / REVIEW / MONITOR / OK 산출
  -> 현재 예측 CSV에 μ·σ·원인·action 결합
  -> 레벨 기반 SS / ROP / target / order / status 계산
```

## 7. 아직 필요한 작업

1. **실증 리드타임 P25 산출기**
   현재는 입력 리드타임에 최소 1일을 적용한다. PDF의 품절 지속일 P25를 품목별로
   산출하고 승인하는 원장 이벤트 추정기는 아직 구현하지 않았다.
2. **승인 분류 확대**
   자동 대체재고 판정은 승인된 기관별 물품 매핑에만 적용된다. 미승인 품목은
   `REVIEW_CLASSIFICATION`으로 남는다.
3. **대체 가능성 임상 검수**
   규격·단위가 같아도 브랜드 전용성, 기기 호환성, 계약 제약이 있을 수 있다.
   자동 승인 전 업무 담당자 검수가 필요하다.
4. **경보 정답 라벨 검증**
   후보 감소율은 정확도나 오탐률이 아니다. 실제 결품·대체 가능 여부의 표본 라벨로
   precision, recall을 평가해야 한다.
5. **간헐수요 정책 고도화**
   정규근사 SS는 간헐·lumpy 수요에서 전제가 약하다. 리드타임 수요 분위수 방식과
   백테스트 비교가 필요하다.
6. **Module C 운영 보정**
   현재 공급위험 정책과 외부 가중치는 잠정 정책이다. 품절·납기 지연 결과 라벨로
   calibration하기 전에는 자동발주가 아니라 권고·검토 용도로 사용한다.

## 8. 검증 원칙

- PDF 수치와 현재 재계산 수치를 별도 표시한다.
- 후보 감소를 정확도 향상으로 표현하지 않는다.
- 대분류만 같은 품목은 자동 대체품으로 보지 않는다.
- 과거 백테스트에는 현재 전체기간 μ·σ를 결합하지 않는다.
- 원시 수요값과 정책 하한 적용값을 모두 보존한다.
- 전체 테스트와 데이터 합계 불변 검증을 통과한 산출물만 사용한다.
