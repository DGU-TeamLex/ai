# 현재 예측모델 종합 평가

작성일: 2026-07-23
원본 데이터: `raw_stock/*.DAT`
예측 단위: `기관 + 부서 + 내부 물품코드`의 다음 달 사용량

## 1. 발표용 결론

1. 로컬 사용량 예측은 최근 3개월 평균 기준선보다 정확하다.
2. 검증 구간에서는 LightGBM L1이 가장 좋아 현재 champion으로 선택됐다.
3. 독립 테스트에서는 LightGBM Tweedie와 Module C 모델이 L1보다 좋았다.
4. Module C 모델은 독립 테스트 WAPE가 가장 낮지만, 순수한 외부 위험 신호 효과로
   해석할 수는 없다.
5. 현재 2026-01 미래 예측은 원본이 2025-12에서 끝나 7개월 오래된 결과다.
6. 현재 결과만으로 자동 발주 정확도나 결품 방지 효과를 입증하지 못했다.

현재 모델 상태를 한 줄로 정리하면 다음과 같다.

```text
로컬 수요예측: 조건부 사용 가능
표준 세부유형 예측: 제한된 파일럿
Module C 위험조정: 실험 단계
2026년 현재 운영예측: 데이터 갱신 전 사용 금지
자동 발주: 검증 부족으로 차단
```

|---|---:|---|

| 월별 행 | 3,729,983 | feature 생성 |
| 로컬 시계열 | 416,128 | 기관·부서·품목 단위 |

학습·검증·테스트는 시간순으로 분리했다. 모델 선택은 테스트 결과를 보기 전에 검증
WAPE로 결정한다. 독립 테스트에서 다른 모델이 더 좋았다는 이유만으로 현재 champion을
바꾸면 테스트 누수가 된다.

최신 미래 예측인 2026-01은 대응하는 실제 사용량이 입력 데이터에 없으므로 정확도
평가에서 제외한다.

## 3. 평가 지표

| 지표 | 의미 | 현재 사용법 |
|---|---|---|
| WAPE | 전체 절대오차 / 전체 실제 사용량 | 주 선택지표 |
| MAE | 행 단위 평균 절대오차 | 일반적인 품목 오차 |
| RMSE | 큰 오차에 더 큰 벌점 | 대량 품목 위험 |
| RMSLE | 상대적 규모 차이 | 소량·장꼬리 품목 |
| SMAPE | 대칭 비율오차 | 보조지표 |
| BIAS_PCT | 총량 과대·과소예측률 | 재고 부족 방향 확인 |

독립 테스트의 실제 사용량 0 비율은 24.37%다. 0 또는 극소 사용량에서 MAPE가
과도하게 커지므로 MAPE를 모델 선택지표로 사용하지 않는다.

```text
BIAS_PCT < 0  -> 전체적으로 과소예측
BIAS_PCT > 0  -> 전체적으로 과대예측
```

### 3.1 현재 수치를 성능으로 해석하는 방법

WAPE 37.54%는 실제 사용량 100단위당 절대오차가 합계 기준 약 37.54단위라는
뜻이다. 설명 편의를 위해 `100 - WAPE`를 가중 정확도 대리지표로 표시하면 다음과 같다.

| 평가 구간 | 모델 | WAPE | `100-WAPE` 대리지표 |
|---|---|---:|---:|
| 검증 | L1 | 40.19% | 59.81% |
| 검증 | Tweedie | 40.77% | 59.23% |
| 검증 | Module C | 40.86% | 59.14% |
| 독립 테스트 | L1 | 38.87% | 61.13% |
| 독립 테스트 | Tweedie | 37.60% | 62.40% |
| 독립 테스트 | Module C | **37.54%** | **62.46%** |
| 독립 테스트 | 최근 3개월 평균 | 40.02% | 59.98% |

`100-WAPE`는 분류 정확도나 "품목의 62.46%를 정확히 맞혔다"는 의미가 아니다.
예측 오차 총량을 이해하기 쉽게 바꾼 보조 표현일 뿐이다. 품목별 정확도, 허용 오차
범위 내 적중률, 예측구간 포함률은 현재 별도로 산출하지 않았다.

WAPE에 공통으로 적용되는 절대적인 합격 등급은 없다. 수요 간헐성, 단위, 결품 비용이
다르기 때문에 이 프로젝트에서는 임의의 `WAPE 40%=합격` 같은 기준을 사용하지 않고,
시간순 기준선 개선폭·총량 편향·주요 품목군 회귀·위험 활성 구간 성능을 함께 본다.

현재 전체 성능은 기준선보다 개선됐지만 매우 높은 수준이라고 보기는 어렵다.

```text
Module C 테스트 WAPE               = 37.54%
3개월 평균 기준선 WAPE            = 40.02%
절대 개선                          = 2.48%p
기준선 대비 상대 오차 감소         = 6.20%
```

대량이 안정적인 검사시약은 L1 WAPE 24.41%로 대리지표가 75.59%지만, 신규 시계열은
Module C WAPE 55.38%로 대리지표가 44.62%다. 따라서 전체 평균 한 개만으로 모든
품목에 같은 자동화 수준을 부여하면 안 된다.

MAE 51.11은 행당 평균 절대오차가 약 51 사용량 단위라는 뜻이다. 다만 정·개·상자 등
서로 다른 단위가 섞여 있으므로 전체 MAE를 "평균 51개 오차"라고 표현하면 안 된다.
운영 허용오차는 표준 세부유형과 단위별로 다시 계산해야 한다.

## 4. 검증 결과

`outputs/stock_model_validation_report.csv` 기준이다.

| 모델 | WAPE | MAE | RMSE | BIAS_PCT | 선택 |
|---|---:|---:|---:|---:|---|
| LightGBM L1 사용량 전용 | **40.19%** | **54.22** | 294.38 | -7.43% | champion |
| LightGBM Tweedie 사용량 전용 | 40.77% | 55.01 | 212.01 | +4.02% | challenger |
| LightGBM Tweedie + Module C | 40.86% | 55.13 | **210.86** | +4.19% | 실험 |
| 최근 3개월 평균 | 44.52% | 60.06 | 234.07 | +5.79% | 기준선 |

L1은 최근 3개월 평균보다 WAPE가 4.33%p, 상대적으로 9.73% 낮다. 따라서 현재
선택 규칙에서는 L1이 champion이다.

Module C 모델은 큰 오차에 민감한 RMSE는 가장 낮지만, 선택지표 WAPE가 L1보다
0.67%p 높다.

독립 테스트에서 Module C 모델은 최근 3개월 평균보다 WAPE가 2.48%p, 상대적으로

L1은 RMSLE는 가장 좋지만 총 사용량을 15.66% 과소예측했다. 재고 부족 비용이 큰
업무에서는 이 편향을 별도로 관리해야 한다.

## 6. 월별 성능

| 목표월 | L1 WAPE | Tweedie WAPE | Module C WAPE | 3개월 평균 WAPE | 월별 최저 |
|---|---:|---:|---:|---:|---|
| 2025-08 | 37.99% | **37.59%** | 37.62% | 40.08% | Tweedie |
| 2025-09 | 39.10% | 36.74% | **36.73%** | 38.46% | Module C |
| 2025-10 | 38.85% | 38.49% | **38.43%** | 41.74% | Module C |

Module C 모델은 5개월 중 4개월에서 가장 낮은 WAPE를 기록했다. 그러나 사용량 전용
Tweedie와의 월별 차이는 작고, 평가월이 5개뿐이므로 모델 전환 근거로는 부족하다.

월별 WAPE 범위는 L1 37.99~39.27%, Tweedie 36.74~38.49%, Module C
36.73~38.43%다. 세 모델 모두 기준선보다 월별 변동 폭은 작았다.

## 7. 수요 패턴별 평가

| 수요 패턴 | N | L1 WAPE | Module C WAPE | 3개월 평균 WAPE | 현재 해석 |
|---|---:|---:|---:|---:|---|
| smooth | 282,783 | 34.84% | **33.17%** | 34.73% | Module C/Tweedie 계열 유리 |
| erratic | 107,186 | **50.38%** | 50.79% | 56.11% | L1 근소 우위 |
| insufficient_history | 41,663 | 48.18% | **45.91%** | 51.88% | 여전히 높은 오차 |
| new_series | 29,577 | 57.41% | **55.38%** | 62.58% | 자동발주 부적합 |
| intermittent | 24,065 | **43.06%** | 43.49% | 46.60% | L1 근소 우위 |
| lumpy | 11,162 | 54.72% | **53.47%** | 56.03% | 별도 간헐수요 모델 필요 |
| all_zero | 109,001 | 72.37% | 98.46% | **68.16%** | 단순 0/휴면 정책 필요 |

모든 수요 패턴에 하나의 모델을 강제하는 것보다, 반복 검증 후 다음 후보를 검토할 수
있다.

```text
smooth·짧은이력·new_series·lumpy -> Tweedie 계열 후보
erratic·intermittent              -> L1 후보
all_zero                          -> 휴면·0 예측 규칙 후보
```

이 라우팅은 현재 테스트 결과에서 도출한 후보일 뿐이며, 신규 기간에서 재현되기 전에는
운영 적용하지 않는다.

## 8. 정규화 상태별 평가

| 정규화 상태 | N | L1 WAPE | Module C WAPE | 3개월 평균 WAPE |
|---|---:|---:|---:|---:|
| family_candidate | 40,233 | **30.94%** | 36.18% | 34.43% |
| group_candidate | 418,220 | 38.40% | **37.55%** | 40.35% |
| unresolved | 146,984 | 48.53% | 37.77% | **36.50%** |

`unresolved`는 L1 성능이 특히 낮다. 다만 로컬 시계열 예측 키는 표준화 상태와 무관하게
유지되므로, 이 차이가 정규화 자체의 인과효과라고 해석하면 안 된다. 품목 구성과 수요
패턴 차이가 함께 포함되어 있다.

`unresolved`에는 단순 기준선이 가장 좋으므로 자동으로 L1을 강제하기보다 fallback
기준선을 유지할 필요가 있다.

## 10. Module C 효과 평가

독립 테스트 산출물은 `module-c-v1.0` 기준이다. 당시 실제로 0보다 큰 Module C 위험이
있던 행은 다음과 같다.

```text
전체 테스트 행        = 605,437
위험이 0보다 큰 행    = 3,300
위험 신호 적용 비율   = 0.545%
최대 Module C 위험    = 0.007441
활성 신호             = Brent 가격 대리변수
뉴스 신호             = 0
무역 신호             = 미포함
```

### 위험 활성 행만 비교

| 모델 | WAPE | MAE | RMSE | BIAS_PCT |
|---|---:|---:|---:|---:|
| L1 사용량 전용 | **45.21%** | **5.11** | **15.98** | -1.80% |
| Tweedie 사용량 전용 | 55.82% | 6.31 | 16.34 | +22.10% |
| Tweedie + Module C | 53.49% | 6.05 | 16.15 | +16.76% |

Module C는 위험 활성 행에서 사용량 전용 Tweedie보다 개선됐지만 L1보다 나빴다.

Module C 모델의 전체 WAPE 개선은 위험이 0인 행에서도 발생했다. 모델을 별도로
재학습하면서 생긴 트리 차이까지 포함되므로, 전체 성능 개선을 외부 위험 신호의
인과효과라고 주장할 수 없다.

현재 `module-c-v1.1`에는 수출입 위험이 추가됐지만, `stock_predictions.csv`와
`stock_backtest_predictions.csv`는 아직 v1.0이다. 따라서 이번 평가에는 수출입
가중치 효과가 포함되지 않는다.

수출입 효과를 평가하려면 다음 조건을 갖춘 동일 모델 ablation이 필요하다.

```text
동일 학습기간
동일 random seed
동일 hyperparameter
동일 feature 집합
trade feature만 on/off
위험 발생 전 학습 -> 위험 발생 후 평가
```

실제 발주량으로 사용하면 안 된다.

현재 재고값이 10만 이상인 행은 21건뿐이지만 전체 현재재고 합의 60.83%를 차지한다.
최대값은 99,999,400이다. 단위 차이, 누적값 또는 sentinel 가능성을 검토하기 전에는
`recommended_order`를 운영 성과평가에 사용하지 않는다.

`outputs/stock_predictions_by_subtype_quality.json` 기준이다.

설명할 수 없다.

## 13. 재고량 모델 평가 한계

현재 정확히 평가한 것은 다음 달 `사용량`이다. 다음은 아직 실제 결과 라벨이 없어
평가하지 못했다.

- 실제 결품 발생 여부와 결품 기간
- 긴급발주 횟수와 비용
- 폐기·유효기간 만료 비용
- 목표 서비스 수준 달성률
- 실제 조달 리드타임
- 권장발주를 실행했을 때의 재고회전일
- 뉴스·가격·무역 사건이 실제 조달에 미친 시간차

따라서 `target_stock`과 `recommended_order`는 정책 계산 결과이지, 효과가 검증된
최적 재고량은 아니다.

## 15. 제안 기준의 현재 충족도

앞서 제안한 모델 전환·운영 기준을 현재 결과에 대입하면 다음과 같다.

| 평가 기준 | L1 | Tweedie | Module C | 현재 판단 |
|---|---|---|---|---|
| 검증 WAPE 최저 | **통과** | 미통과 | 미통과 | L1 champion 유지 근거 |
| 기준선 대비 WAPE 3%p 개선 | 검증 통과, 테스트 미통과 | 검증 통과, 테스트 미통과 | 검증 통과, 테스트 미통과 | 독립 테스트에서 전부 부족 |
| 검증·테스트 절대 편향 5% 이내 | 미통과 | **통과** | **통과** | Tweedie 계열이 안정적 |
| 신규 rolling 평가 2회 연속 우위 | 미평가 | 미평가 | 미평가 | 2026년 실제값 필요 |
| 주요 품목군 2%p 이상 회귀 없음 | 기준 모델 | 미확정 | 미통과 | Module C가 일부 군에서 악화 |
| 외부 위험 활성 subset 개선 | 해당 없음 | 미통과 | 미통과 | L1보다 WAPE가 높음 |

### 15.1 기준별 실제 수치

검증에서는 L1, Tweedie, Module C가 최근 3개월 평균보다 각각 4.33%p, 3.75%p,
3.66%p 개선되어 3%p 기준을 통과했다. 독립 테스트 개선폭은 각각 1.15%p,
2.42%p, 2.48%p로 모두 3%p에 미달했다.

편향 기준은 차이가 분명하다.

| 모델 | 검증 BIAS_PCT | 테스트 BIAS_PCT | 절대 5% 기준 |
|---|---:|---:|---|
| L1 | -7.43% | -15.66% | 두 구간 모두 미통과 |
| Tweedie | +4.02% | -4.51% | 두 구간 모두 통과 |
| Module C | +4.19% | -4.32% | 두 구간 모두 통과 |

Module C는 테스트 5개월 모두 L1보다 WAPE가 낮았고, Tweedie와 비교하면 5개월 중
4개월 우위였다. 이는 challenger 재검토 근거는 되지만, 같은 고정 테스트 구간을 여러
번 나눈 결과다. "신규 rolling 평가 2회" 조건을 충족한 것으로 계산하지 않는다.

Module C는 L1과 비교해 의료소모품에서 7.48%p, 주사제에서 5.07%p, 검사시약에서
3.12%p 악화되어 주요 품목군 회귀 제한을 통과하지 못했다.

외부 위험이 실제 활성화된 3,300행에서도 L1 WAPE 45.21%보다 Module C WAPE
53.49%가 8.28%p 높았다. 현재 기준에서 Module C의 외부 위험 반영 성능은 미통과다.

따라서 현재 기준의 종합 성능 판정은 다음과 같다.

```text
L1:
  상대오차 선택기준은 가장 안정적이지만 과소예측 편향이 큼

Tweedie:
  검증 WAPE는 L1보다 조금 나쁘지만 편향과 독립 테스트 성능이 안정적

Module C:
  전체 테스트 성능은 가장 좋지만 외부 위험 대상과 일부 주요 품목군에서 검증 실패

현재 결론:
  L1 champion 유지 + Tweedie challenger 병행
  Module C는 v1.1 동일조건 ablation 전까지 실험 상태 유지
```
