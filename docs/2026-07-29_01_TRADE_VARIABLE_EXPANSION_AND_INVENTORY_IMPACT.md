# 수출입 변수 확장 및 재고 영향 결과

## 1. 적용 범위

관세청 HSK 월별 수출입 총계와 국가별 수입 자료를 원자재-HSK 승인 경로에 연결하고,
수출입 위험을 기존 4개에서 10개 변수로 확장했다. 계산 설정은
`module-c-v1.2`이며 모든 계수는 아직 실증 인과계수가 아닌
`policy_seed_requires_backtest` 상태다.

원천 자료:

| 구분 | 현재 값 |
|---|---:|
| 승인 원자재-HSK 경로 | 32 |
| 승인 원자재 코드 | 28 |
| HSK 코드 | 32 |
| 총계 관측 | 1,340 HS-월 |
| 국가별 관측 | 4,962 HS-국가-월 |
| 기간 | 2023-01~2026-06 |
| 설정 국가 | 20개 |
| 현재 캐시에 수집된 국가 | CN, DE, IN, JP, US |
| 국가 커버리지 80% 통과 | 582 / 1,340 HS-월 |

## 2. 확장 변수와 가중치

각 위험값은 0~1 범위다. 임계값 이상이면 1이며, 관측할 수 없는 변수는 위험 0과
가용성 0으로 처리한다. 이때 `trade_signal_confidence`가 함께 낮아지므로 결측을
정상 상태로 오인하지 않는다.

| 변수 | 계산 개요 | 가중치 | 위험 1 기준 |
|---|---|---:|---:|
| 수입량 감소 | 전년동월 대비 수입중량 감소 | 0.20 | 30% 감소 |
| 순수입 가용량 감소 | `max(수입중량-수출중량, 0)`의 전년동월 감소 | 0.10 | 30% 감소 |
| 수입 중단 | 과거 양수 수입 후 수입 0인 연속월 | 0.10 | 2개월 |
| 수입단가 상승 | `수입액/수입중량` 전년동월 상승 | 0.15 | 40% 상승 |
| 수입량 변동성 | 최근 6개월 수입중량 변동계수, 최소 3개월 | 0.10 | CV 0.50 |
| 수입단가 변동성 | 최근 6개월 단가 로그변화 표준편차, 최소 3개월 | 0.10 | 0.20 |
| 공급국 집중 | Top1 점유율과 HHI 중 큰 값 | 0.10 | 0.50 초과분 |
| 공급국 수 감소 | 커버리지 통과 국가 수의 전년동월 감소 | 0.05 | 30% 감소 |
| 순수입 노출 | `max(수입액-수출액, 0)/수입액` | 0.05 | 100% |
| 수출량 급증 | 수출중량 전년동월 증가 | 0.05 | 50% 증가 |

HS 위험:

```text
hs_trade_risk = Σ(변수 위험 × 변수 가중치)
```

품목 경로:

```text
path_weight
  = 품목-원자재 mapping_weight
  × exposure_score
  × mapping_confidence
  × 원자재-HS mapping_weight
  × HS proxy_quality

item_trade_risk
  = 1 - Π(1 - hs_trade_risk × path_weight)
```

Module C 결합:

```text
trade_pressure = 0.25 × item_trade_risk
supply_risk = 1 - (1 - base_supply_risk) × (1 - trade_pressure)
```

## 3. 데이터 가용성 게이트

- 전년동월 자료가 없으면 YoY 기반 변수는 사용하지 않는다.
- 과거 양수 수입이 없고 현재도 0이면 수입 중단으로 판정하지 않는다.
- 국가별 추적 수입액이 총수입액의 80% 미만이면 집중도와 공급국 수 변수를 사용하지
  않는다.
- 공급국 수 감소는 현재월과 전년동월 모두 커버리지 기준을 통과해야 한다.
- 수출량 급증은 전년동월 수출중량이 양수일 때만 계산한다.
- 위험 점수와 별도로 사용 가능한 변수 가중치의 합을
  `trade_signal_confidence`로 저장한다.

설계돼 있어 무역 단독 경보는 0건이다.

## 7. 남은 보완

1. 국가별 캐시는 현재 5개국만 수집됐다. 설정된 20개국을 증분 수집하면 국가
   집중도와 공급국 수 변수의 가용 HS-월을 늘릴 수 있다.
2. HSK가 정확히 승인되지 않은 약성분과 원자재에는 무역 점수를 적용하지 않는다.
   유사명 자동 승인은 금지하고 공식 HSK 근거를 추가해야 한다.
3. 순수입 노출은 국내 생산량을 포함하지 않으므로 엄밀한 수입의존도가 아니다.
4. 현재 가중치와 임계값은 정책 초기값이다. 실제 품절, 조달 리드타임, 구매단가,
   긴급발주 결과를 목표변수로 시계열 백테스트한 뒤 재보정해야 한다.
5. 재고 단위 표준화 전에는 품목 간 증가량 합계를 성능지표로 사용하지 않는다.
