# TabM 전체 자료 실험 결과

## 판단

이번 설정은 기존 LightGBM을 대체하지 않는다. 2025년 10~12월 전체 359,335행에서 WAPE는 기존 34.734137%에서 TabM 35.511808%로 0.777671%p 악화했다. BIAS는 -6.632005%에서 -2.691214%로 줄었지만, 개별 예측의 절대오차는 증가했다. 과다예측과 과소예측이 상쇄되면 BIAS만 좋아질 수 있으므로 이를 정확도 개선으로 해석하지 않는다.

월별 WAPE도 모두 악화했다. 10월은 34.7520%에서 35.7454%, 11월은 34.7438%에서 35.2556%, 12월은 34.7104%에서 35.5432%다. 서비스와 기존 기준 모델은 변경하지 않는다.

## 학습과 검증

첫 구간은 2,675,790행으로 학습하고 242,034행에서 검증했다. 선택 회차는 16회이며 WAPE는 기존 36.318898%에서 36.023688%로 낮아졌다. 두 번째 구간은 3,039,785행으로 학습하고 246,103행에서 검증했다. 선택 회차는 4회이며 WAPE는 기존 34.692004%에서 34.944571%로 높아졌다.

두 구간을 합산하면 35.487851%에서 35.472455%로 0.015395%p 개선하는 데 그쳤다. 사전에 정한 수치상 선택 규칙에 따라 selection.json에는 TabM이 기록됐지만, 이는 서비스 채택이나 유의미한 개선의 확인이 아니다. 두 시점에서 방향이 달랐고 재사용 평가에서는 악화했으므로 대체 근거가 부족하다. 10~12월 자료는 이전에도 평가한 기간이므로 독립적인 최종 검증이라고 부르지 않는다.

입력은 기존 74개 변수이며, 범주 표현·학습 기간만으로 계산한 정규화·규모 보정 절대오차 손실을 적용했다. 상세 설정은 같은 폴더의 선정 및 실행준비 문서에 사전 기록했다. 학습은 CPU 2스레드에서 순차 진행했고 회차별 모델·옵티마이저·난수 상태를 로컬에 저장했다. 소규모 표본의 점수를 전체 결과로 제시하지 않았다.

## 종료 오류와 수정

학습 후 정답 대조에서 저장 정밀도 차이가 발견됐다. 준비된 특성 파일의 정답은 float32이고 기존 평가 파일은 float64다. 표본 키 359,335행은 전부 일치했으며 470개 정답의 최대 차이는 약 0.00004883이었다. 느슨한 허용 오차로 검사를 없애지 않고, 기존 정답을 준비 파일의 자료형으로 변환했을 때 정확히 같은지 검사하도록 수정했다. 실제 평가는 기존 평가 파일의 원래 정답으로 두 모델을 함께 계산했다. 한 단위가 다른 정답을 거부하는 회귀 테스트를 추가했으며 전체 테스트 5개가 통과했다. 학습을 다시 하지 않고 평가 단계만 한 번 재실행했다. 기존 실패 로그와 체크포인트는 보존했다.

## 원인 해석과 다음 가설

이번 실험은 모델 구조를 바꿔도 같은 정보만으로 큰 개선을 확보하지 못했다는 증거다. 모든 신경망이 부적합하거나 이 데이터에서 35% 이하가 불가능하다는 증거는 아니다. 이번 설정은 단일 seed·제한된 폭·수치 변수 임베딩 미사용이며, 논문 기본 설정의 완전한 재현도 아니다. 검증 회차 선택에도 반복 비교에 따른 낙관성이 있을 수 있다.

다음 가설은 과거에 알 수 있는 사용 상태에 따라 별도 모델을 학습하는 방식이다. 기존 오차 감사에서는 짧은 연속 이력과 중간 변동 표본이 전체 절대오차의 약 73%를 차지했다. 이전 전체 잔차 모델·일괄 혼합과 달리 해당 집단의 학습 자체를 분리해 서로 다른 패턴을 하나의 모델이 절충하는 영향을 점검한다. 미래 사용량이나 사후 오차로 집단을 만들지 않아야 한다. 이 가설은 아직 이번 작업에서 실행하지 않았으며, 먼저 과거 검증 집단별 TabM·기존 모델의 오차 차이와 학습 표본 수를 확인한 뒤 실행 조건을 고정해야 한다. 같은 TabM 설정을 그대로 반복하지 않는다.
